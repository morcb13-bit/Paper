同じ目盛りで並べる殻の球

小さな正三角形の一辺をすべての殻でそろえる。殻 n の球は半径が n に比例して大きくなる

前の図では殻ごとに球の大きさをそろえていた。ここでは逆に、網の小さな正三角形の一辺をすべての殻で同じにする。殻 n の網は一辺 n の正四面体を割ったもので、球へ投影すると角までの長さ²は 3n²。殻を同じ中心に重ねると、K・L・M・N は半径 1・2・3・4 の比で外へ広がり、O・P・Q は点対称の鏡像の網として同じ大きさを戻る。

数えた値（整数）

殻n向き角までの長さ²小さな辺²点−2累計

小さな辺²は平らな網での値で、どの殻でも 8。角までの長さ²は 3n²（1：4：9：16）、半径の比は 1：2：3：4。向きは、O から先が点対称の鏡像の網。濃い点は元の正四面体の角。

座標の置き方

網の点は a·V₁＋b·V₂＋c·V₃（a＋b＋c＝n、V は正四面体の角 (±1,±1,±1)）。n で割らないので、小さな辺はどの殻でも同じ長さになる。鏡像は符号を入れ替えたもの。球への投影だけが観察者側の換算。

網の点・面・辺の数と、点＝辺−面＋2 の確かめは整数だけで行っている。球面へ押し出す長さの換算と、画面に置く回転・投影だけに浮動小数を使う（観察者側の表示）。殻の数との対応は数の一致として示している。
