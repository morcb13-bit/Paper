ずらして重ねる星型八面体

殻ごとに一つの星型八面体（正四面体と点対称の鏡像、中心は共通）。一辺 1・2・3・4・4・3・2 を軸に沿ってずらして重ねる

一つの殻は、一辺 n の正四面体とその点対称の鏡像を同じ中心に重ねた星型八面体。三回軸に垂直な面が二枚（正四面体の底面と鏡像の底面）あり、どちらも n² 個の小三角形に割れて、合わせて 2n²。殻ごとの星型八面体を軸に沿ってずらして重ねる。ずらす量を 0 にすると、すべて同じ中心の入れ子になる。

座標の置き方

殻 k（k＝0,1,…）の中心は c＋k·d·(1,1,1)。正四面体は中心から n(1,1,1)・n(1,−1,−1)・n(−1,1,−1)・n(−1,−1,1)、鏡像は符号をすべて入れ替えたもの。大きな辺²は 8n²、面を割った小さな辺²は 8。全体の中心がそろうよう c を整数で決める。

座標・長さ²・個数はすべて整数で求めている。浮動小数は画面に置く回転と投影（観察者側の表示）だけに使う。殻と副殻の対応は知識として置いたもので、図の中では数の一致だけを示している。
