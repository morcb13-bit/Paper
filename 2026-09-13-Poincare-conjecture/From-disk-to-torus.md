## はじめに

ペレルマンのポアンカレ予想の解決策の説明の中で、リッチフローの手術という概念が出てくるが、これは誰が手術するのかということがずっと気になっていた。

**図2：境界付近の断面**
![](https://static.zenn.studio/user-upload/c0332b22d351-20260831.png)

この図の上は垂直断面、下の図は水平断面だと見てほしい。この図を立体にすると、**楕円体とトーラス**になることがわかるだろう。2つの図はそれぞれ別の数式で表せるが、両方の極限を離散的な整数値で飛び越えるアイデアを思いついた。

円盤とトーラスは別の形だ。片方には穴が無く、片方には穴がある。
トポロジーで見ても全く別のものだ。それをつなぎ合わせるのがリッチフローの手術だった。

筆者は、以前、下記のような楕円体 ⇔ 二様双曲面 ⇔ 一様双曲面へとシームレスに移行する3Dグラフィックを描いている。

**図3 ：楕円体 ⇔ 二葉双曲面 ⇔ 一葉双曲面へとシームレスに移行する3Dグラフィック**
@[codepen](https://codepen.io/morcb13-bit/pen/PwWmjbV?default-tab=result)
https://zenn.dev/morc_b13/articles/c09da88597400a

**6つの曲線を統合する**

- **楕円体・一葉・二葉** … $\lambda$ 族の本体（図2が動かす 3 枚）。
- **楕円錐** … 退化。係数が 0 になる閾値そのもの（図2の赤い縦線）。
- **楕円放物面・双曲放物面** … $e=1$ の境界。片焦点が無限へ逃げる極限で、**2 次元の放物線が 3 次元へ繰り上がった**もの。「6 種の曲線」は、同じ空間を別の視点での観察にすぎない。

今回は、楕円体からトーラスへ極限を飛び越えてスムーズに移行する図だ。その二つを一本のつまみで繋いだ図を作ってみた。
連続の量はどこにも入っていない。それでも、楕円体からトーラスへ渡る。
連続では描けないものが離散では描ける。

この記事はその図と、図を作るのに使った量の話だ。

## 1. 円盤からトーラスにスムーズに変化させられるか？見えているもの


**図4：円盤からトーラスに変化する図**
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a05541-23c3-7dc4-98bb-7c500c373ab4?default-tab=result)

つまみ `μ` は `−4, −3, −2, −1, 0, 1, 2, 3, 4` の九段。

- `μ > 0` … 中心に厚みがある。穴は無い
- `μ = 0` … 厚みがゼロ。境界
- `μ < 0` … 穴が開いている

段の間に何も入れていない。`μ = 1` の次は `μ = 0`、その次は `μ = −1`。三段で渡りきる。

ここで注意しておきたいことが一つある。厚み `2√μ` と穴の半径 `√−μ` は無理数になるが、**それは格子の出力であって入力ではない**。格子に入っているのは `μ` だけで、`μ` は整数しか取らない。

そして `μ = 0` では `1/μ` が発散する。しかし格子は `1/μ` を使っていない。だから発散は図のどこにも現れず、段が一つ進むだけになる。

**（見立て）発散する量を格子の定義に入れないかぎり、ゼロの座は行き止まりではなく通過点になる。**

---

## 2. つまみを何にするか

このつまみは、半径そのものではない。半径の**二乗**を符号つきで持ったものだ。

半径 `r` を主役にすると、`r = 0` は端になる。`r < 0` に意味が無いからだ。しかし `μ = ±r²` と符号つきで持てば、`μ = 0` は端ではなく並びの一つになる。

```
μ > 0  →  中心の厚み = 2√μ
μ = 0  →  極点
μ < 0  →  穴の半径 = √(−μ)
```

同じことを、円錐曲線の族で見慣れた形に書くと、

```
(x² + y²) / μ = 1
```

分母の符号だけで、詰まっているか抜けているかが切り替わる。場合分けは要らない。

**（見立て）**この記事で実際に起きているのは、円盤がトーラスになることよりも、**変数の取り替えで境界の意味が変わること**だと思う。`r ≥ 0` の世界では `r = 0` は端で、そこで話が終わる。`u = r²` として符号を許すと、`… −2, −1, 0, 1, 2 …` という一本の軸になり、`0` は端ではなく途中の一点になる。平方根の側で「消滅」だったものが、二乗の側では「符号が変わる場所」になる。

---

## 3. 境界の近くを切る

上段は回転軸を含む面での断面、下段は軸に垂直な中央面での断面。`μ` を `2, 1, 0, −1, −2` と一段ずつ進めてある。

上段の中央の縦の太さが `2√μ`。太さが消えた所が `μ = 0` で、そこから先は下段が輪になる。

段の間を細かく刻んでいないことに注意してほしい。境界を跨ぐのに、間に無限の細かさは要らない。

## 4. ここで、別の測定を並べる

以下は上の図とは別の場所で出た数値で、**この記事はこの二つを繋ぐ主張をしない**。並べるだけにする。

回転対称な三次元球面を `ψ(ρ, t)` 一本で持って、リッチフローで流したときの式は

$$
\frac{\partial\psi}{\partial t}=\psi_{ss}-(n-1)\frac{1-\psi_s^2}{\psi}
$$

この式では、`ψ → 0` で右辺の第二項が発散する。首が細る所で解が終わる。

**図5：リッチフローの首**
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a0554e-1435-7079-a301-c0f2f44afc9f?default-tab=result)

**（計算）**首の半径 `r` を追うと、`r` そのものは有限時刻 `T` でゼロに落ち、そこで首の曲率が発散する。一方で `r²` は時刻に対して直線で落ちる。走らせ役の測定では、`T = 0.0004895`、`r²` の一次あてはめの傾きが `−1.857`。肩のほうはほとんど動かない（`0.42555 → 0.42300`）。細るのは首だけ。

ここで、`ψ` ではなく `u = ψ²` を未知数に取って式を書き直すと何が起きるか。

$$
\psi_s=\frac{u_s}{2\sqrt u},\qquad \psi_{ss}=\frac{u_{ss}}{2\sqrt u}-\frac{u_s^2}{4u^{3/2}}
$$

を代入して整理すると、

$$
u_t=u_{ss}+\frac{(n-2)\,u_s^2}{2u}-2(n-1)
$$

`n = 2` で中間の項が消えて、

$$
u_t=u_{ss}-2
$$

**（計算）**定数項 `−2(n−1)` は `n = 2` で `−2`。上に書いた測定の傾き `−1.857` と同じ側の数字になる。

**（計算）**この変換は恒等式として検算してある。任意の `ψ` について両辺が一致する（`n = 1, 2, 3, 4` で差は `10⁻¹⁵` の桁）。`n = 2` で中間項が消えることは、その項を落として確かめた ── 落とすと `n = 1, 3, 4` では壊れ、`n = 2` でだけ一致が戻る。また丸い三次元球面では `u_t = u_ss − 2` が厳密に成り立ち、`r² + 4t` が一定になる。

そして、この形の式には、少なくとも明示的に `u = 0` を禁じる `1/u` の項が無い。

以上が並べる内容で、ここから何かを引き出すことはしない。

この節の式と数値の出どころ：

- Angenent–Knopf, *An example of neckpinching for Ricci flow on S^{n+1}*, Math. Res. Lett. 11 (2004), 493–518 — [PDF](https://people.math.wisc.edu/~angenent/preprints/MRLrevision2.pdf)
- Perelman, *Ricci flow with surgery on three-manifolds*, [arXiv:math/0303109](https://arxiv.org/abs/math/0303109)

## 5. 確かめていないこと

三つある。どれも、何が出たら何が言えるかを書いておく。

**(i) `u` が `0` を横切って解が続くか。**

式に `u = 0` を禁じる項が無いことと、`0` を横切っても解が続くことは、別のことだ。

`u_t = u_ss − 2` の `∂_s` は弧長についての微分で、弧長そのものが時間で動く。走らせるには長さの側の式も同時に回す必要があり、首が潰れる所ではその長さの側が退化する。格子を張り直さないと通らない。

**走らせていない。**通せば、`u` の最小値が有限時刻でゼロを横切り、その先も滑らかに続くはず、というのが予測になる。横切る所で壊れれば、そこまで。

**(ii) 負の側に何が住むか。**

`u < 0` で式は生きているが、`ψ = ±√u` は実でない。式が記述していた面が向こう側に無い。何を置くかは、こちらが決める話であって、式が決めてくれる話ではない。**この記事は決めていない。**

**(iii) 有限時刻 `T` が、つまみの目盛りに乗るか。**

図の閾値は整数だが、`T = 0.0004895` は測った数で整数ではない。**整数なのは閾値であって、時刻ではない。**この二つを同じ文に並べる書き方は、いまはできない。

## ６. 結論

この図とリッチフローの手術の関係は、**同じ軸の別の刻みに立っている**ということです。
ただし、この図は離散的な9段階の刻みで、リッチフローの手術は連続で動く刻みだ。
