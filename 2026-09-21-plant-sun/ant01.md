前回までは、脳を持たずオートマトンで動くだけの**アメーバ型ロボット**を試したが、今回は、最小限の学習機能を持たせた**アリ型**ロボットに発展させた。まだ、開発途中だが、作動原理がわかる動く図と要件定義書だけを載せておく。
学習にも浮動小数わず、整数値のみで動く装置である。

## アリ型ロボット配送センター 要件定義書

本書は、女王アリ（中央の管制）と働きアリ（自律型ロボット）が協働して、荷物を取り出し出荷口へ運ぶ配送センターの要件を定める。誤配0・迷子0・取り残し0を最優先とし、間違えてはならない判断は固定の規則で、速く・うまくなる部分だけを学習で行う。

## 目的と範囲

働きアリロボットは、女王アリ（管制）の「番地 n にある札 k の荷物を持ってこい」という指示を受け、取りに行き、札を確かめ、巣（出荷口）へ持ち帰る。

- 範囲：配送センターの中のピッキングと帰巣、複数台の譲り合い。
- 範囲外：積み付け、建物の外への配送、人との受け渡し。
- 前提：女王アリ（中央）が注文と全体への指示を出し、アリは自律して動く。経路は中央で計算しない。各個体は自分の番地と隣だけを見る。判定は整数の比較と足し算だけで行う。

## 用語

| 名前 | 配送センターでの役 | 装置の中のもの |
| --- | --- | --- |
| 巣 | 出荷口・充電所・指示の出どころ | 中心の五芒星 |
| 女王アリ | 管制（在庫の台帳を持つ） | 番地と札番号の対応表 |
| 床 | 倉庫の通路と棚 | 扇10枚の担体（五角形）＋舟・細ひし形・五芒星 |
| 番地 | 棚の位置 | 五角形の位置（Z\[ζ\] の4整数） |
| 匂い | 行き先への道しるべ | 行き先からの段数（足し算で回す層） |
| 札 | 荷物の識別ラベル | 目印・静かな帯・符号・写し |
| 脳 | 経験の蓄え | 番地ごとの札（0/1/2…の整数） |
| 通票 | ぶつからない決まり | 一つの番地に一刻一体 |
| 駅・待機所・エレベーター | 待避線・待機場・層の乗り換え | 舟・細ひし形・五芒星 |

## システム構成

中央が受け持つのは配車と全体への指示だけで、歩き方・探し方・読みは各個体が自分で行う。

| 構成要素 | 受け持つこと | 持つもの |
| --- | --- | --- |
| 女王アリ（管制） | 注文の受付、配車、全体への指示、通れない番地の配布、報告の受付 | 在庫台帳（番地と札番号）、各個体の状態 |
| 働きアリ（ロボット） | 移動、道の記憶、札の探索と読み、照合、帰巣、伝言の中継 | 網膜、脳（番地ごとの札）、燃料 |
| 床 | 通路と棚 | 番地（五角形）、舟・細ひし形・五芒星 |
| 巣 | 出荷口・充電・指令の発信 | 無線の届く範囲 |
| 札 | 荷物の識別 | 目印・静かな帯・符号・写し |
| 通信 | 指令と報告 | 無線（巣のまわり）＋アリからアリへの伝言 |

## 一回の仕事の流れ

1. 女王アリが配車指令（番地 n、札番号 k）を無線で流し、近くにいて先に了解を返したアリに割り当てる。
2. 行き先へ向かう。脳にその行き先への道の札があればそれをたどる。無ければ匂いをたどり、通った道を札に残す。
3. 道が塞がっていれば、隣だけを手探りして脇道を探す（深さを決めた範囲）。見つかれば札に書き足す。無ければ巣へ戻り、通れない番地を報告する。
4. 一歩ごとに、次の一歩の先で残りの燃料が巣までの段数を下回るなら引き返す。
5. 番地 n に着いたら、荷物の面で札を探す。脳が札のありそうな向きを示し、視線をそちらの五芒星へ跳ばす。
6. 目印・静かな帯・写しがそろった所でだけ符号を読む。k と一致すれば持つ。違えば持たない。
7. 来た道の札を逆にたどって巣へ戻り、結果を女王アリへ報告する（持ち帰り／札違い／札が見つからない／通れない）。
8. 他の個体とは通票で譲り合う。舟で待避し、細ひし形で待ち、五芒星で層を替える。

## 機能要件（女王アリ）

| 番号 | 要件 | 合格条件 | 失敗時の扱い |
| --- | --- | --- | --- |
| Q1 | 注文を受け付ける | 番地と札番号を台帳と照らし、在庫の無い注文は受けない | 断った注文を記録する |
| Q2 | 配車する | 無線で指令を流し、近くにいて先に了解した一体に割り当てる。二重の割り当て 0 | 了解が無ければ指令を流し直す |
| Q3 | 全体へ指示する（避難など） | 全個体に届く（圈外は伝言で中継）。取り残し 0 | 決めた刻数で応答の無い個体を記録する |
| Q4 | 通れない番地を配る | 報告を受けたら全個体へ配る | — |
| Q5 | 報告を受ける | 5種の報告をすべて記録し、台帳を更新する | — |

## 機能要件（働きアリ）

合格の基準は、どれも走らせる前に決める数である。試行数は4000を基本とする。

| 番号 | 要件 | 検定と入力 | 合格条件 | 失敗時の扱い |
| --- | --- | --- | --- | --- |
| F1 | 指示を受ける | 注文4000件（番地・札番号） | どの注文も一体だけに割り当てられ、その一体が受ける（二体が同じ荷物へ向かう回数 0） | 指示の不備は女王アリへ返す |
| F2 | 匂いで行く | 床と行き先、障害物なし | 着かない回数 0 | 巣へ戻り「通れない」と報告 |
| F3 | 道を覚える | D7：一回目は匂い、二回目は匂いなし | 4000/4000 着いて戻る | 匂いをたどり直し、札を書き直す |
| F4 | 脇道を探す | D7：固定の障害物＋動く障害物（個数と動きは事前に固定） | 迷子 0、次回は障害物に突き当たらない | 巣へ戻り、通れない番地を報告 |
| F5 | 引き返す | D4：燃料 E 歩 | 戻れない回数 0 | 残量不足は「燃料切れ」として迷子と分けて数える |
| F6 | 札を探す | D6：荷物の面（汚れ3割）、札は任意の角度 | 跳躍の平均が近い順の走査を2回を越えて下回る | 面を全部見て無ければ「見つからない」で戻る |
| F7 | 札を読む | D5：札1枚、任意の角度、汚れ3割 | 違う番号 0 | 検査がそろわなければ読まない |
| F8 | 照合して持つ | 置き間違いを1割混ぜる | 違う荷物を持ち帰る回数 0 | 持たずに戻り「札違い」と報告 |
| F9 | 報告する | 全注文 | すべてが5種（持ち帰り・札違い・見つからない・通れない・燃料切れ）のどれかで終わる | — |
| F10 | 譲り合う | 複数台。誰が行くかは女王アリの配車で決まる | 通票ありの持ち帰り数が通票なしを上回る（差の基準は事前に決める） | 待機が続けば巣へ戻る |
| F11 | 学びを積む | K1a：回を重ねる | 札の書き換えが減り、成績が下がらない | 下がった回は前の札を残す |
| F12 | 全体への指示（避難など） | 女王アリが出す。電波の届く範囲は巣のまわりに限る | 全個体が受け取り、指定の場所へ戻る。取り残し 0 | 決めた刻数のあいだ何も届かなければ、自分で巣へ戻る |
| F13 | 伝言で中継する | 電波の外のアリへ、近くのアリからアリへ渡す（渡せる距離は番地の段数で事前に固定） | 電波の外の全個体に決めた刻数以内に届く。途中で中身が変わらない（写しの一致で確かめる） | 届かない個体は F12 の扱い |

## 非機能要件

| 項目 | 要件 |
| --- | --- |
| 誤配 | 0件。最優先で、速さより前に置く |
| 迷子 | 0件。迷ったら巣へ戻る |
| 演算 | 整数の比較と足し算だけ。GPU・浮動小数を使わない |
| 中央計算 | 経路の中央計算をしない。各個体は自分の番地と隣だけを見る |
| 説明 | どの注文も、通った番地の列・読んだ札・乗り換えた場所が整数で残る |
| 規模 | 台数・床の広さ・札の種類を増やしても、誤配0と迷子0を保つ |

## 脳が学ぶもの・学ばないもの

間違えてはいけない部分（F5・F7・F8・F9）は固定の規則で行い、速く・うまくなる部分（F3・F4・F6・F10・F11）だけを学習にする。脳は経験を札として番地に残し、次の行動を変える。

| 分け | 中身 | 札の形 | 学び方 |
| --- | --- | --- | --- |
| 学ぶ | 道（行き先ごとの次の一歩） | 番地ごとの「次の隣」 | 一度たどれば書く。塞がれば書き足す |
| 学ぶ | 札のありそうな向き | 網膜の番地ごとの最初の層 | 見せた例で積み重ねる（K1a） |
| 学ぶ | 混む場所 | 乗り換えの札 | 待たされた番地で層を替える |
| 学ばない | 札の符号の読み | 目印・静かな帯・写しの一致 | 固定の照合 |
| 学ばない | 引き返し | 燃料と巣までの段数 | 固定の比較 |

## 決定事項

- [x] 札の角度：任意。読みは向きに依らない（72°刻み以外はまだ検定していない）
- [x] 燃料：残量不足は「燃料切れ」として、迷子と分けて数える
- [x] 障害物：固定と動くものの両方。個数と動きは検定の前に固定する
- [x] 通れない番地の伝え方：女王アリへ報告し、女王アリが全体へ配る。電波の届かない場所ではアリからアリへの伝言で中継する（F12・F13）。触れ合って伝える形（アリの触角）は後に回す
- [x] 誰が取りに行くか：女王アリが決める。タクシーの配車のように無線で指令を流し、近くにいて先に了解したアリに割り当てる。学習させない
- [x] 札：一つの荷物に1枚。複数枚は別の検定にする

## 前提と制約

- 判定は整数の比較と足し算だけで行う。GPU・浮動小数は使わない。
- 床は扇10枚の担体で、番地は五角形の位置を Z\[ζ\] の4整数で表す。
- 検定の数値は計算機上の模型で出したもので、実機の速度・電池・センサーの誤差は含まない。

## 範囲外・後回し

- 触れ合って伝える形（アリの触角）
- 一つの荷物に複数枚の札
- 72°刻み以外の角度の札の読み（要件には入れたが未検定）
- 積み付け、建物の外への配送、人との受け渡し
