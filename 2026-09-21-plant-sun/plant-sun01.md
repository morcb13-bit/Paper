## 第一部　植物の成長モデルをオートマトンで描く

植物は、東から昇って西へ沈む太陽を毎日浴びながら育ちます。太陽が動くことこそが、二葉ができて枝分かれしていく要因であり、そうでなければもやしになる ── これが監督の読みです。

この記事では、ペンローズの担体の上に「明るいほうへ一歩伸びる」だけのオートマトンを置き、その読みを装置の中で確かめます。数値はすべて Claude の計算です。

## 1. 装置

担体は、五角形10枚の円環を1行目から14行目まで三角形に積んだものです。五角形は721枚、その隙間に五芒星が36個あります。

規則は次の四つだけです。

```
芽      五芒星に置く
見る    五芒星のまわりの五角形5枚が、光のセンサー
伸びる  5枚のうち最も明るいものがただ一つ → その向きの隣の五芒星へ
二葉    最も明るいものが二つ並ぶ → 両方へ
止まる  三つ以上が並ぶ → 伸びない
```

太陽は十分遠いものとして、平行な光で照らします。明るさは、五角形が太陽の方向へどれだけ出ているかで決まります。

## 2. 星の二つの向き

五芒星には向きが二種類あります。最上段の星と同じ向きのものを a、36°回った向きのものを b と呼びます。

```
a の尖り    18°・90°・162°・234°・306°
b の尖り    54°・126°・198°・270°・342°
（画面の向き。右が0°、下が90°、上が270°）
```

担体の中で、星は段ごとに a と b が交互に積まれています。

```
1a, 1b, 2a, 2b, 3a, 3b, 4a, 4b, 5a, 5b, 6a
```

最初の二段は、向きの逆な星が一個ずつの「1, 1」です。

## 3. 二葉が起きる条件

最も明るい五角形が二つ並ぶのは、光が星の尖りの延長線上にあるときだけです。尖りの線は五角形2枚のちょうど真ん中を通るので、そこで明るさが揃います。

太陽が空にあるとき、線に乗る機会は次の順に来ます。

```
b 342°（日の出の直後）→ a 306°（朝）→ b 270°（正午）→ a 234°（午後）→ b 198°（日没の前）
```

1日のうちに、a と b が交互に分かれる機会を迎えます。

光を担体の中の一点に置いた場合も、同じ形が出ます。下から光へ近づいた枝は a の星で、上から近づいた枝は b の星で分かれます。

```
14行・光を星に置いた全配置     a の分岐    b の分岐
出発が光より下（575配置）        2602         210
出発が光より上（575配置）         151        2314
```

## 4. 太陽が止まっているとき

太陽を真上（270°）に止めたまま、地面の星6個から3日間伸ばしました。

```
分かれた回数   b 270°：42
夕方の先端     6個の出発すべてで、頂点の星一つ
```

分かれること自体は何度も起きます。けれども、分かれた枝はその日のうちに光の真下の一点へ引き戻され、一本に寄ります。**枝分かれとして残りません。**これが、この装置の中のもやしです。

## 5. 東から西へ渡る太陽

1日を13コマとし、太陽を東の地平（0°）から18°ずつ空を渡らせて西の地平（180°）まで動かす11コマと、夜の2コマにしました。夜は伸びません。

```
分かれた回数   a 234°：6   a 306°：2   b 270°：2
               （3で挙げた機会の方位の外では0）
1日目の夕方   6個の出発すべてで、先端が左右に二つ残る
```

太陽が動くと、分かれた枝は離れたまま一日を終えます。朝と午後に a の星で分かれ、その枝を引き戻す一点がありません。

2日目には、どちらの枝も担体の頂点に着きます。この担体は頂点が上の三角形なので、空に向かう側が一点に細っています。何日も続けて枝を増やすには、空に向かって広がる担体が要ります。

動く図で、この二つを切り替えて見られます。開くとすぐ動き始めます。

## 6. 付記：六角との接点

最後に、六角形とのあいだに見えているものを並べておきます。

**確かめたこと（Claude の計算）**

- 担体を14行まで積むと、五角形はちょうど721枚になります。ハエの視覚系モデル FlyVis の六角形の受容器と同じ数です。
- 行を一つ積むたびに下の行と共有される五角形は 3, 3, 6, 6, 9, 9, … と増え、偶数行 N = 2m の五角形数は m(13m + 12) になります。14行は m = 7 で、7 × 103 = 721 です。
- これが中心つき六角数 3k(k+1) + 1 と等しくなる条件は、X = 13m + 6、Y = 6k + 3 と置くと 12X² − 13Y² = 471 の形になります（観察者側の整理として言えば、ペル型の方程式です）。解は無限に続き、最小が14行、次が38行（4921枚）です。
- 配線は六角と一致しません。隣り合う五角形の枚数は2〜4で、6は一つもありません。

**知識として持っているだけのこと（検算していない）**

- FlyVis の721は、中心から15周の六角形です。
- 植物の成長ホルモン（オーキシン）の輸送の計算模型には、六角形の細胞を並べた格子の上で組まれるものがあります。

**わかっていないこと**

- 六角形の上のオーキシンと、この装置の二葉がどう対応するのか。

## まとめ

明るいほうへ一歩伸びるだけのオートマトンでも、二葉は起きます。起きるのは、光が星の尖りの延長線上に来たときだけです。

太陽が止まっていると、分かれた枝は光の真下の一点へ引き戻され、一本の茎になります。太陽が東から西へ渡ると、朝と午後に a の星で分かれた枝が、離れたまま一日を終えます。

**枝分かれを残すのは、太陽が動くことです。太陽が動かなければ、植物はもやしになります。**

## 第二部 模擬植物を作る

今度は、第一部の植物成長モデルの担体を360度に広げて動く図「模擬植物」を作りました。今度は根も葉もあります。

植物は、東から昇って西へ沈む太陽を毎日浴びて育ちます。太陽が動くことが枝分かれの要因で、そうでなければもやしになる。

この記事では、ペンローズの担体の上に、光の向きを桁として溜めて閾値で発火するだけのオートマトンを置き、枝分かれと枝の消去がどこから出てくるかを確かめます。数値はすべて Claude の計算です。

## 1. 担体

担体は、五角形10枚の円環を三角形に積んだものです。1段目に1環、2段目に2環、…と14段まで積むと、105環・五角形721枚になります。三角形の頂角は36°です。

この三角形は、それ自体が局所の規則で育ちます。円環どうしの一歩は、短・長 × 左下・右下の4通りしかありません。

```
内側  下の段の隣り合う二つの円環の、両方から一歩で届く点   → いつもちょうど一つ
端    端の円環から外へ一歩。隣の新しい円環と段内の間隔で接し、
      その間隔が親の段の端の間隔と違うもの                → ちょうど一つ
```

種を1段目と2段目（1環・2環）にすると、3段目から14段目まで、積んだ担体と一環も違わずに育ちます。

36°の三角形を中心のまわりに一周並べます。72°ずつ回した5枚は重ならずに置けますが、36°ずつの10枚は五角形の向きが合わず重なります。5枚の間に残る36°の隙間には、36°回した1枚を外へ一段ずらして入れます（監督の指定）。ずらす量は、重ならずに収まる位置がただ一通りしかありません。

```
72°ずつ5枚 ＋ 隙間に36°回して一段ずらした5枚  → 1050環・五角形7200枚、十角形の一周
```

## 2. 桁と発火

円環の表面の五角形（他の生きている円環と共有していない五角形）が、太陽の向きで桁を一つ出します。

```
円環の中心から見た五角形の向きと、太陽の向きの角度
  36°未満 +2 ／ 72°未満 +1 ／ 108°未満 0 ／ 144°未満 −1 ／ それ以上 −2
```

円環の内側の十角形が、表面の桁と、円環一つにつき毎コマ +1 を足して溜めます。桁は平衡5進で、±3 に達すると ∓5 して ±1 を送り出します（発火）。

```
+1  まだ無く、親がすべて生きている子のうち、太陽に最も向いたものへ
−1  生きている親のうち、太陽から最も背けたものへ
    向きが同点のときは二つとも受け取る（二葉）
```

子の場所も平衡5進の一桁として溜め、+3 に達すると円環が生まれ、生きている円環が −3 に達すると消えます。どこにも行き先がない ±1 は外へ出し、入れた桁と、溜まりと、発火と、外へ出た量の帳尻を毎コマ取ります。

足した規則はここまでで、枝分かれの規則も、枝を落とす規則もありません。

## 3. 昼と夜

1日は20コマです。昼の11コマ、太陽は地平から地平へ18°ずつ渡り、夜の9コマは出ません。夜は太陽の桁が0になり、円環の +1 だけが続きます（昼と夜は監督の指定）。

## 4. 光と影で何が変わるか

同じ規則のまま、太陽の与え方だけを変えて40日育てます。

```
                        生きている  生まれた  消えた  二葉   成長
太陽なし                   1050     1020       0   1200   担体が全部埋まる
一周ずっと光る（夜なし）       38      391     383      0   11日目で止まる
昼と夜                      137     3188    3081    129   40日目まで続く
```

太陽がないと、桁は +1 だけになり、担体は対称に全部埋まります。消える円環は一つもありません。

夜がなく一周光り続けると、陰の側の −1 が絶えず溜まり、生まれた円環の大半がすぐ消えます。11日目を最後に誕生も消去も止まり、二葉は一度も出ません。

昼と夜があると、夜のあいだ陰の桁が止まり、昼に生まれた円環が夜を越して残ります。昼は太陽の側へ伸び、正午前後に向きが揃う場所で二葉が出ます。40日目まで生まれて消えるが続き、中心から10方向へ枝が分かれた形になります。

太陽の道を逆向き（西から東）にすると、どの場合も東から西の結果の鏡映と全コマで一致します。帳尻もすべてのコマで合っています。

## 5. 模擬植物

図を上下逆にして太陽を上から当て、担体の中心の高さを地面にします。地面より上が茎、下が根です。

茎の規則はこれまでどおりです。根は土の中で光を受けないので太陽の桁は0とし、+1 は夜だけ入ることにしました（根を遅くするための選び方で、光を受けず毎コマ +1、光から逃げる桁、と比べていちばん遅く伸びる形です）。

```
      生まれた  消えた
茎     1071    1026
根      510       0   （18日目に根の側が埋まって止まる）
```

根では円環が一つも消えません。根に入るのは +1 だけで、−3 に届くことがないからです。この装置では、消去は陰の桁からしか生まれません。光と影の両方がなければ、枝の消去は起きません。

茎は昼ごとに太陽の側へ枝を分けては消え、根はゆっくり土を満たしていきます。形の外枠は担体が決めていて、太陽と昼夜はその中のどこが生きるかを選んでいます。

## 6. 先行研究（観察者側の整理）

光が木の形を決めるという数理模型は、これまでにもあります。Borchert と Honda（1984）は二又に分かれる枝の発達を計算機で模擬し、Sachs と Novoplansky（1995）は、木の形は決まった設計図ではなく枝どうしの競争による自己組織化で生まれると論じました。Palubicki、Prusinkiewicz ら（2009）は、芽と枝が光と空間を競う過程から木の形を生成し、受ける光が閾値を下回った枝を落とす規則を入れています。

この記事の模擬植物は、そこに規則を足していません。枝分かれは太陽の桁の同点から、枝の消去は陰の桁の繰り上がりから、同じ一つの桁の足し算として出てきます。計算は整数と加算だけです。

## まとめ

ペンローズの担体の上で、光の向きを平衡5進の桁として溜め、閾値で発火させるだけのオートマトンを動かしました。太陽がなければ担体は全部埋まって消去は起きず、夜がなく光り続ければ成長は止まり、昼と夜があるときだけ、枝を分けて伸びては消える形が40日続きました。

枝分かれとアポトーシスは、光と影の一つの桁から両方出てきます。植物は、太陽があるから枝分かれします。
