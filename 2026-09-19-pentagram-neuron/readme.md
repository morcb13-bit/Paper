# 五芒星ニューロン模型

ペンローズの担体に空く五芒星の隙間へ、正十二面体を面ひとつで伏せる。網膜側（担体）が場所を決め、記憶側（立体）が桁を持つ二部構成。外から持ち込んだ数はなく、倍率も距離も余裕もすべて φ の冪で出る。

監督の呼び名：ペンローズ・バーチャル・プロセッサー（PVP）。

```
python3 pentagram_neuron.py
```

```
検定DF4   五芒星の中心間の最小距離        OK
検定DF13  30×5=150通りの札               OK
検定NE3   60歩の閉路と各点の通過回数      OK
検定NE1   書いて読む                     OK
検定NE2   空試験                         OK
検定NE1b  出発点を変える                 （測定。60通り→60通り）
検定IF1   二つの焦点からの r²             OK（負の対照 0/200）

NG 0 / 7
```

`pentagram_neuron.py` が実際に走らせるのは上の七つ。寸法（DF1〜DF3・DF5）、結合（DF6・DF8）、番地（DF9〜DF12）、係数（IF2）の数値は引継書 v256 に載っているが、このスクリプトには再現の形で入れていない。

## 装置

**寸法** ── 五芒星の隙間は10頂点で、中心からの距離は二種類しかない。凹頂点が φ⁻¹（方位54°）、尖りが φ（方位18°）、内と外の向きの差が36°。正十二面体の面をこの隙間に揃えると、内側に伏せる倍率が φ⁻¹、尖りまで使う倍率が φ、外側÷内側が φ² になる（差はいずれも 1e-08 台）。

負の対照として、担体の他の三種の隙間は φ の冪にならない。

```
正十角形  1.902113           φ¹ との差 2.8e-01
細ひし形  1.118034 / 0.363271      差 1.2e-01 / 1.9e-02
舟       2.148133 / 0.570634      差 4.7e-01 / 4.7e-02
```

**五芒星だけが乗る。**向きも36°ずれで決まるので、外から指定する数がない。

**衝突しない** ── 五芒星の中心間の最小距離は φ⁴（35対が同距離）。面を伏せた正十二面体（辺長1）の投影の最大半径は φ²/√(2+φ)、高さは φ³/√(2+φ)。内側に伏せると投影半径がちょうど担体セルの外接半径 1 に一致し、尖りまで使うと φ² で余裕が φ。

**番地** ── 五芒星に接するのは五角形10枚だけで、細ひし形は30個すべてで接しない（座標・輪郭・番地の三通りで確認）。まわり10枚は距離が φ と φ² の二種、向きの列は 0,1,0,1,… で30個すべて同じ。72°回すと重なり（30/30）、36°では重ならない（0/30）。72°対称が破れるのは φ² まで読んで26個、φ³ で4個。読む範囲を担体の端まで広げると、30個 × 5回転 = 150通りの札がすべて異なる。

> **有限であることは担体の制約ではなく、番地が一意になる条件である。**

無限のタイリングなら5回対称の中心に座る五芒星が残り、永久に破れない。縁があるから全部の札が別になる。

**記憶** ── 対角線60本の閉路は60歩で全辺を一度ずつ通り、各点をちょうど3回通る。したがって桁は頂点には置けない（1点1桁だと読み出しが3重になる）。桁は対角線60本に置く。60 = 12面 × 5本 なので、五芒星1枚あたり5桁は変わらない。分裂頂点60 と対角線60 は、面の向きを一つ決めれば一対一に対応する。

60桁に平衡5進数の列を書いて60歩で読むと順序を含めて完全に戻り、何も書かずに読むと全ゼロになる。ただし出発の取り方を変えると読み出し順も全部変わる（60通り→60通り）ので、**立体だけでは番地が決まらない。**固定するのが担体側の150通りの札。

**二つの測定がここで噛み合う。**立体だけなら読み始めが決まらず、担体だけなら記憶する場所がない。

**容量**

```
正十二面体1個   面の五芒星12枚 × 5桁 = 60桁 ＝ 分裂した頂点の数と一致
担体30個        1800桁
網膜の符牒      30個 × 5ビット = 150ビット
1800 ÷ 150 = 12 → 正十二面体1個がちょうど12コマ分。面が12枚で、伏せた1枚が入力
```

網膜が返す符牒の番地と、記憶を持つ五芒星の番地は同じ30個。読み替えの表が要らない。

**結合** ── 立体の内側（対角線60本）は次数6で一定・連結。立体どうしを φ⁴ で繋ぐと35本・連結30/30・次数1〜3（葉6個）。次数のばらつきは縁だけが理由ではなく、外周を除いた24個でも 3/6/15 とばらつく。**内側は規則正しく、外側は不揃い。**端子としては足りるが、立体間を渡り歩く探索には使えない。二部構成ではそもそも渡り歩かない。

**干渉** ── 隣り合う二つの五芒星（距離 φ⁴）を焦点に取ると、30個すべてで両方からの r² が黄金整数 p + qφ になる（負の対照：でたらめな200点は 0/200）。係数の列にフィボナッチとリュカが出る。

```
(0,0) (13,21) (47,76) (89,144) (107,173) (170,275) (188,304)
(259,419) (277,448) (295,477) (387,626) (423,684) …
13,21 = F₇,F₈ ／ 89,144 = F₁₁,F₁₂ ／ 47,76 = L₈,L₉
```

**源が二つ、円波が広がり、交点だけが実在する。**交点の番地が整数二つで書ける。

## まだ書いていないもの

- **変換の規則。**動いているのは記憶まで。60歩の巡回は読み出しであって、入力を別の何かへ移す規則ではない
- **NE4**：伏せた面の5頂点と担体の五芒星の5頂点の対応。向きは5通りに絞れ、0桁目は札で決まるが、札をどう読んで頂点に割り当てるかの手続きがない
- **NE5**：一歩あたり θ を 72°/60 = 1.2° 進める割り当て。別記事からの借用で、五芒星に伏せた状態では検算していない
- **MR1〜MR3**：検定IF2 で星2と星3、星4と星5 が同じ (p,q) を持つ。左右の対を全部拾い、軸の上の星の残渣を出し、軸から外した三つめの焦点で対が破れるかを見る。基準は書けているが未実施
- **厳密演算への置き換え。**距離の判定は現状すべて浮動小数と許容差で書いてある。黄金整数への還元も同じ。Z[φ] の整数対だけで書き直す作業は未実施（`dodeca_exact.py` が同じ型の先例）

**未照合の一致**：投影の最大半径 φ²/√(2+φ) = 1.376382 は、黄金のひし形三十面体（RT）の中心から面までの距離 h_min と同じ値。算術の一致であって、同じものだとは言えない。突き合わせる検定は書けるが未実施。

## 量子計算との対応（観察者側の整理）

```
干渉         あり  二族の交点が位置を決める
可逆         あり  60歩の閉路。何も捨てない
位相         あり  一歩1.2°、60歩で72°（借用・未検算）
測定で落ちる  あり  θ=0 の縮退でだけ読める
重ね合わせ    無し  60桁はどれも一つの値に決まっている
もつれ       無し  置いていない
```

五つのうち四つ。重ね合わせが無い以上、量子計算の利得そのものは出ない。可逆・周期・測定で落ちるの三つは古典的な可逆オートマトンでも成り立つので、外形が似ているだけの可能性が高い。

左右の対についても、離れていて対応が保たれるのは事実だが、両方とも最初から決まっている。決まっているものが一致しているのは相関であって、もつれではない。

## 検定の書き方

負の対照が入っているのは DF2（他の隙間は φ の冪にならない）、NE2（何も書かずに読むと全ゼロ）、IF1（でたらめな200点は 0/200）の三つ。他の検定には入っていない。

判定は OK / NG を表示し、最後に NG の本数を出して終わる。**落ちない検査は、何が出ても意味がない。**
