## はじめに

2026年10月7日、ノーベル化学賞が東京理科大学の硤合憲三名誉教授と、フランスのアンリ・カガン博士に贈られることになりました。授賞理由は「不斉有機合成における非線形効果と自己触媒の発見」です[^1][^2][^3]。

硤合先生は1990年に、生成物が自分と同じ型をつくる触媒になる反応を報告しました[^4]。1995年には、2%のわずかな偏りが、この反応で自分を足し込んで88%まで増幅されることを示しました[^5][^6][^13]。前者からは36年、後者からは31年になります。その後の研究では、ごくわずかな偏りから3回の反応で99.5%以上に達することも示されています[^13]。

分子には、右手と左手のように、鏡に映すと重なる二つの型があります。生物のアミノ酸がほぼ片側の型だけでできている理由は、生命の起源に関わる問いとして残っています。硤合反応が注目されてきたのは、この問いに「小さな偏りが全体を決める」という具体的な道筋を見せたからです。

この記事では、この出来事を整数と足し算と比較だけの装置に写します。まず硤合反応の生成物の立体模型で、右型と左型の違いと、作り分けに何が要るかを見ます。続く二枚の動く図で、1個の差がどういう条件で全体に広がるかを確かめます。化学反応の説明ではありません。同じ出来事を、加算だけという別の視点から離散化して見たものです。本記事は、受賞者や関係機関とは関係のない、個人による読み物です。

## 右と左を、＋と−に置く

右型を＋、左型を−と置きます。

- 右型の数を $N_+$、左型の数を $N_-$ とします。
- 差を $D = N_+ - N_-$ とします。

右と左が同数の状態は $D=0$ で、片側に寄った状態は $D \neq 0$ です。図では、＋を赤、−を青で塗ります。

## 図1：硤合反応の生成物を立体で見る

右型と左型は、何が違うのでしょうか。まず、硤合反応で実際に合成される分子を立体の模型にして確かめます。

模型にしたのは、1-[2-(tert-ブチルエチニル)ピリミジン-5-イル]-2-メチルプロパン-1-オールです。2025年の機構研究でも扱われた系の生成物で、この系では数回の反応で鏡像体の偏りが99.5%以上まで増幅されることが知られています[^8]。中心の炭素には、次の4つが付いています。

- 水素（H）
- ヒドロキシ基（OH）
- イソプロピル基（iPr）
- ピリミジン環（環）

原子の座標は、化学計算ライブラリ RDKit（2026.03.6）[^11]で、標準的な結合の長さと角度から組みました。結晶で実測した座標ではありません。中心の炭素を原点にとり、0.01Å を1とする整数に直してあります。

中心から4つの腕の先までの距離の二乗は、H が 11963、OH が 20530、環が 22449、iPr が 23918 です。4本の腕は長さも向きもそろっておらず、腕の先がつくる形は、正四面体ではないただの四面体です。

- **② 重ねてみる**：S体を回して、中心の炭素・iPr・環の3つをR体に重ねます。重ねたとき、OH と H の場所が入れ替わります。

### 右か左かは、四面体の向きの符号で決まる

四面体が正四面体でなくても、右と左は区別できます。H・OH・iPr・環の先の原子の座標から、次の行列式を整数で計算します。

$$
s = \det[\,\mathrm{OH}-\mathrm{H},\ \mathrm{iPr}-\mathrm{H},\ \mathrm{環}-\mathrm{H}\,]
$$

この座標模型では、R体で $s = 8122130$、S体で $s = -8122130$ です。分子をどう回しても、この符号は変わりません。鏡に映したときだけ符号が反転します。整数の座標で確かめた結果は次のとおりです。座標の軸を入れ替えたり向きを反転したりする整数の行列48通りのうち、回転にあたる24通りでは符号はすべて保たれました。鏡映を含む24通りでは、符号はすべて反転しました。右か左かは、この符号の＋と−そのものです。

### 作り分けに要るもの

③の型紙で、作り分けに何が要るかが分かります。

受け口の三角形（OH・iPr・環の先がつくる三角形）は、R体とS体で同じ形です。辺の長さの二乗は、どちらも 59112、65333、56325 です。そのため、受け口が3つあるだけでは、S体も三角形をぴったり合わせられ、どちらもはまります（図の「板の裏表 なし」）。

違いが出るのは、板に表と裏があるときです。3つの受け口に合わせると、R体では H が板の表側に来ます。S体では、同じように合わせると H が板の裏側に突き抜けます。H がどちらの側に来るかも、行列式の符号として整数で判定できます。

**この模型で右と左を作り分けるには、3つの受け口に加えて、表と裏を区別する拘束が要ります。** 実際の分子の認識には、三点ではなく四点で考える模型などもあり、ここで言えるのはこの模型の中のことだけです。 型紙をどこから持ってくるかで、作り分けには二つの道があります（ここで挙げる化学の例は、化学の側の知識を借りた観察者側の整理です）。

1. **外から型紙を与える。** 片方の型だけでできた触媒を型紙にして、反応のたびに同じ型を着地させます。2001年にノーベル賞を受けた野依良治先生らの不斉触媒は、この道です[^10]。カガン博士が見つけた非線形効果は、この型紙が右と左の混ざりものだったときに起きる振る舞いです。
2. **できたものが型紙になる。** 硤合反応では、生成物そのものが、次の分子をつくるときの型紙の一部になります。型紙を外から与えなくても、最初にわずかに多かった側が、自分と同じ型を写していきます。

二つ目の道では、最初の小さな偏りが全体に広がるかどうかが問題になります。続く二枚の図は、この「広がるかどうか」を見るためのものです。

## 三つの操作

装置に許す操作は三つだけです。

1. **写す（足し込み）**
   空いた席は、両隣の値を足し、正なら赤、負なら青で埋まります。同じ型が同じ型を呼ぶ、自己触媒の写しです。
2. **組で消える**
   赤と青が隣り合うと、組になって両方とも空席に戻ります。両側から1個ずつ引くので、差 $D$ は変わりません。
3. **混ぜる**
   色を見ずに、席の並びを $k$ 飛びに読み直します。型は一切見ません。

外から「右へ行け」と向きを与えることはしません。乱数も使いません。

## 判定の基準

走らせる前に、何が出たら何が言えるかを整数の比較だけで決めておきます。

- **増幅（F1）**：ある歩以降、$|D|$ がずっと初期値の2倍以上にとどまる。
- **飽和（F2）**：最後の状態で `20 × 同じ側の数 ≥ 19 × 占有数` が成り立つ（占有の95%以上が同じ側）。あわせて、占有数が初期より減っていないこと。
- **対照**：赤と青が同数の初期状態では、$D=0$ が最後まで保たれる。
- **負の対照**：写す操作がない規則では、F1が通らない。
- **鏡像**：赤を1個足した場合と青を1個足した場合で、結果の赤と青がそのまま入れ替わる。

### 席を持たない器でも同じ

席の並びを持たず、すべての分子が互いに出会える器でも確かめました。材料は10万個で、赤51・青50から始めます。

| 規則 | 最後の（赤, 青） | 増幅 | 飽和 |
|---|---|---|---|
| 足し込みなし | (51, 50) | NG | NG |
| 足し込みだけ | (50307, 49794) | OK | NG |
| 足し込み＋組で消える | (99901, 0) | OK | OK |

足し込みだけでも、差は1から513まで増えます。それでも両側はほぼ半々のままです。差が増えることと、片側にそろうことは別の段です。

一歩で消える組の数を1組・10組・100組と制限しても、結果は片側にそろいました。変わるのはそろうまでの歩数（49765歩、4948歩、0歩）と、最後に残る量だけです。組で消える操作は $D$ を変えないので、少ない側だけが先に0に達します。

一方で、足し込みのない器で組を消すだけだと、最後は (1, 0) になります。片側だけにはなりますが、残るのは1個です。少ない側を消して片側だけを残すことと、小さな差を足し込んで全体を片側で満たすことは、別の出来事です。判定の基準に「占有数が初期より減らない」を入れてあるのは、この二つを分けるためです。

## 図3：ペンローズの担体

最後に、同じ規則をB13の担体の上で走らせます。

担体は、五角形10枚の円環を60個つないだペンローズの図です。五角形は420枚あり、1枚を席1つとします。辺を共有する五角形どうしを隣とし、隣かどうかは、中心どうしの距離の二乗が $\varphi^2$ に等しいかを、$\mathbb{Z}[\varphi]$ の整数の対で比べて決めます。隣の数は、2が260枚、3が140枚、4が20枚です。

種は、鏡に映すと互いに重なる五角形の対を3組選び、片方に赤、もう片方に青を置いたものです。そのうえで、どこか1枚に赤を1個足します。この足す場所を、ここでは着地と呼びます。

どこまで片側に寄るかは、着地で決まります。最後の状態で、同じ側が占有の何割を超えたかを、20等分の段で数えました（`20 × 同じ側 ≥ q × 占有` を満たす最大の $q$）。

| 装置（席420） | 段10（半々） | 段17以上（85%以上） | 段19（95%以上） |
|---|---|---|---|
| ペンローズの担体 | 66 | 101 | 0 |
| 輪 | 189 | 0 | 0 |
| 方眼（20×21） | 36 | 51 | 1 |

## 中心の規則（整数と比較だけ）

```python
def step(x, nb, k):
    n = len(x); y = list(x)
    for i in range(n):                       # 写す：空いた席を隣の和の符号で埋める
        if x[i] == 0:
            s = 0
            for j in nb[i]: s += x[j]
            if s > 0: y[i] = 1
            elif s < 0: y[i] = -1
    z = list(y)
    for i in range(n):                       # 組で消える：隣り合った赤と青を空席に戻す
        if y[i] != 0:
            for j in nb[i]:
                if y[j] == -y[i]: z[i] = 0; break
    if k == 0: return z
    w = [0] * n; j = 0
    for i in range(n):                       # 混ぜる：席を k 飛びに読み直す（色は見ない）
        w[i] = z[j]; j += k
        while j >= n: j += -n
    return w
```

`nb[i]` は席 $i$ の隣の一覧です。輪なら両隣の2席、ペンローズの担体なら辺を共有する五角形です。図2と図3は、この同じ規則を動かしています。

## 二人の発見との対応（観察者側の整理）

ここからは、化学の側の知識を借りた整理です。

- 型紙が3つの受け口で右と左を見分けるという考え方は、化学では三点結合の模型として古くから知られているものに当たります。この記事では原典を確認していません。図1の③では、3つの受け口に加えて板の表と裏が要ることを、整数の符号で確かめました。

- 硤合先生の自己触媒は、この記事の「写す（足し込み）」に当たります。
- カガン博士らは1986年の論文で、触媒の偏りと生成物の偏りが比例しない非線形効果を報告しました[^7]。説明として知られているのは、右型と左型が一つの金属に組んだ錯体が、同じ型どうしの錯体とは違う働きをする、という模型です。この記事の「組で消える」は、右型と左型が同時にあると増幅に寄与しない、という抽象化した対照規則です。実際の硤合反応で起きている錯体の形成や反応の速さを、この一規則で表しているわけではありません。
- 近年の機構研究（ミュンヘン大学のトラップらのグループ、2025年・2026年）では、硤合反応の触媒の本体は、生成したアルコールがアルデヒドに付いてできる一時的な亜鉛の錯体だとされています。右型と左型で別々の錯体ができ、その錯体ができる速さが一周の速さを決めていると報告されています[^8][^9]。この記事の「写す」は、この二段を一段にまとめて写したものです。
- 「混ぜる」は、溶液がかき混ぜられていることを抽象化した対応です。図2の②と③の違いは、出会いが局所に限られる装置では、組で消える操作が全体に届かないことを示しています。

## おわりに

右型と左型は、どう回しても重ならず、その違いは四面体の向きの符号の＋と−として整数で書けます。見分けられるのは、受け口3つと表裏のある面がそろった型紙だけです。型紙を外から与えれば作り分けになり、できたものが型紙になれば、わずかな偏りが自分を写して広がります。

1個の差を全体へ広げるために、装置の中で要ったのは三つでした。

1. 写すこと（足し込み）：差が増える。
2. 組で消えること：差を保ったまま、少ない側が先に尽きる。
3. 混ぜること：出会いが全体に届く。

写すだけでは、差が増えても半々のまま止まりました。組で消えるだけでは、片側にそろっても1個しか残りませんでした。隣だけを見る輪では、境目で固まりました。試した組み合わせの中で、1個の差が全体を片側で満たしたのは、三つがそろったときだけでした。ペンローズの担体の上でも同じで、増幅はどこに着地しても起き、全体を満たすには混ぜる操作がもう一段要りました。

どれも、足し算と比較だけで書ける操作です。31年前に示された「わずかな偏りが大きな偏りへ増幅される」という現象を、化学反応そのものを再現するのではなく、足し算と比較だけの離散規則に写してみました。この規則と、この検定の範囲では、三つの操作がそろった場合に同じ種類の増幅が現れました。
