## 動く図で見る化学（その1）― 共有結合 ―

## はじめに

分子の結合を、正四面体を組み合わせた模型として動く図で見ていきます。その1は共有結合です。

使う材料は一つだけです。

- 立方体の一つおきの頂点で作る正四面体（座標は ±3 の整数）

炭素や酸素を、この正四面体として置きます。中心から4つの頂点へ向かう線を**腕**と呼びます。二つの原子が頂点・辺・面を共有すると、腕どうしがそこで出会い、結合になります。

ここでやるのは、よく知られた分子の形を、整数と足し算で書ける模型に**離散化して並べる**ことだけです。結合を説明する学説を置き換えるものではありません。

正四面体の頂点・辺・面の共有で単結合・二重結合・三重結合を表す見方は、19世紀のファント・ホッフの模型としてすでにあります（観察者側の整理として参照）。この記事では、それを整数の座標で組み直し、どの腕がつながり、どの腕が残るのかを図で追います。

図の腕は4色に塗り分けます。

| 色 | 腕の状態 |
|---|---|
| 灰 | まだ決まっていない腕 |
| 紫 | 相手とつないだ腕 |
| 青 | 水素がついた腕 |
| 橙 | 自分の電子2個で埋まった腕 |

どの図も、「離れている → 近づく → 出会った腕がつながる → 残った腕が埋まる」の4段で動きます。ドラッグで回すこともできます。

## 1. 正四面体を整数で組む

立方体 $(\pm 3, \pm 3, \pm 3)$ の頂点を一つおきに選ぶと、正四面体になります。

$$
A = \{(3,3,3),\ (3,-3,-3),\ (-3,3,-3),\ (-3,-3,3)\}
$$

中心は原点です。腕の長さ² はどれも 27、腕どうしの内積はどれも −9 です。組（内積, 長さ²）は (−9, 27) で、これが正四面体の角です。

相手の正四面体は、共有する場所で A を折り返して作ります。

- **頂点**を共有する：共有する頂点で点対称に折り返す
- **辺**を共有する：辺の中点で点対称に折り返す
- **面**を共有する：面の平面で鏡に映す

どの折り返しも、整数の座標のまま閉じます。

```python
A = [(3, 3, 3), (3, -3, -3), (-3, 3, -3), (-3, -3, 3)]

def sub(a, b): return tuple(x - y for x, y in zip(a, b))
def add(a, b): return tuple(x + y for x, y in zip(a, b))
def dot(a, b): return sum(x * y for x, y in zip(a, b))

def point_reflect(p, m2):          # 中心 m の点対称（2m を渡す）
    return sub(m2, p)

def plane_reflect(p, n, d):        # 平面 n·x = d での鏡映
    t = 2 * (dot(n, p) - d)
    nn = dot(n, n)
    assert t % nn == 0             # 割り切れることを確かめる
    return tuple(x - (t // nn) * y for x, y in zip(p, n))

single = [point_reflect(p, (6, 6, 6)) for p in A]          # 頂点 (3,3,3) を共有
double = [point_reflect(p, add(A[0], A[1])) for p in A]    # 辺 A0–A1 を共有
triple = [plane_reflect(p, (1, 1, -1), 3) for p in A]      # 面 A0A1A2 を共有
```

## 2. 単結合 ― 腕1本ずつで頂点をつなぐ

**図1：単結合 ― 腕 1 本ずつで手をつなぐ**（Bond1 single.html）
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a1379d-5101-7aa3-a974-5c51a8805ca6?default-tab=result)


二つの炭素が頂点を一つ共有すると、それぞれの腕が1本ずつ、その頂点で出会います。これが単結合です。残った腕3本ずつに水素がつき、エタン C₂H₆ の形になります。

B13 側で出した値は次のとおりです。

- 相手の炭素の中心は (6, 6, 6)。中心どうしの長さ² は **108**
- 空いた腕から見た組は、相手の中心に対して (−18, 27, 108)。角は正四面体のまま
- 両側の空いた頂点3つずつは、結合の軸から見て互い違いに並ぶ

腕の勘定：炭素2個で8本 ＝ つないだ腕2本 ＋ 水素の腕6本

## 3. 二重結合 ― 腕2本ずつで辺をつなぐ

**図2：二重結合 ― 腕2本ずつで辺をつなぐ**（Bond2 double.html）
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a137a9-e9e9-7d45-86d8-2fbf258393b4?default-tab=result)

二つの炭素が辺を一本共有すると、それぞれの腕が2本ずつ、辺の両端で出会います。これが二重結合です。残った腕2本ずつに水素がつきます。

- 相手の炭素の中心は (6, 0, 0)。中心どうしの長さ² は **36**
- 空いた頂点4つ (−3, 3, −3)、(−3, −3, 3)、(9, −3, 3)、(9, 3, −3) は、**同じ平面に乗る**（法線 (0, 72, 72)、4点とも y＋z＝0）

水素4個が一枚の平面に並ぶので、エチレン C₂H₄ は平らな形になります。エチレンが平らな分子であることは記録と一致します（観察者側の整理として参照）。

腕の勘定：炭素2個で8本 ＝ つないだ腕4本 ＋ 水素の腕4本

## 4. 三重結合 ― 腕3本ずつで面をつなぐ

**図3：三重結合 ― 腕3本ずつで面をつなぐ**（Bond3 triple.html）
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a137c9-273b-703c-a425-5b97a6faf584?default-tab=result)

二つの炭素が面を一枚共有すると、それぞれの腕が3本ずつ、面の三つの角で出会います。これが三重結合です。残った腕は1本ずつです。

- 相手の炭素の中心は (2, 2, −2)。中心どうしの長さ² は **12**
- 空いた頂点 (−3, −3, 3) と (5, 5, −5) は、二つの中心を結ぶ**軸の上に乗る**（外積が 0）

水素は炭素と同じ一直線の上につき、アセチレン C₂H₂ はまっすぐな形になります。これも記録と一致します（観察者側の整理として参照）。

腕の勘定：炭素2個で8本 ＝ つないだ腕6本 ＋ 水素の腕2本

## 5. 共有が増えると、長さ² は3で割れる

三つを並べると、次の表になります。

| 共有 | 出会う腕 | 中心どうしの長さ² | 空いた頂点の並び | 形 |
|---|---|---|---|---|
| 頂点 | 1本ずつ | 108 | 互い違い | エタン |
| 辺 | 2本ずつ | 36 | 一枚の平面 | エチレン |
| 面 | 3本ずつ | 12 | 一直線 | アセチレン |

中心どうしの長さ² は、共有が一段増えるたびに **3 で割れて** 108 : 36 : 12 ＝ 9 : 3 : 1 になります。どの場合も、空いた腕から見た角は正四面体の (−18, 27, ·) のまま変わりません。変わるのは中心どうしの距離と、空いた頂点の並び（立体・平面・一直線）だけです。

## 6. 一酸化炭素 CO ― 面を共有し、埋まった腕が残る

**図4：三重結合 ― 腕3本ずつで面をつなぐ**（Bond4 co.html）
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a137cc-2379-72b9-8e45-d9015d411474?default-tab=result)

酸素の正四面体にも腕が4本あります。水素のいない分子では、相手とつながなかった腕は**自分の電子2個で埋まります**。

CO では、炭素と酸素が面を一枚共有し、腕が3本ずつ出会います。炭素にも酸素にも埋まった腕が1本ずつ残り、どちらも分子の軸の上を外向きに向きます。

腕の勘定：炭素と酸素で8本 ＝ つないだ腕6本 ＋ 埋まった腕2本

## 7. 二酸化炭素 CO₂ ― 向かい合う二辺で腕を使い切る

**図5：二酸化炭素 CO₂ ― 向かい合う二辺で腕を使い切る**（Bond5 co2 .html）
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a137d0-82a4-7450-bfd5-37d1a6973a73?default-tab=result)

CO₂ では、炭素の正四面体の**向かい合う二辺**を、左右の酸素とそれぞれ共有します。腕は2本ずつ出会い、炭素の腕4本はすべてつながります。

- 左右の酸素の中心は (6, 0, 0) と (−6, 0, 0)。和は (0, 0, 0) で、O＝C＝O は**一直線**
- 共有した二辺の向き (0, 6, 6) と (0, 6, −6) の内積は **0**。二つの辺は互いに直交する

CO₂ がまっすぐな分子であることは記録と一致します（観察者側の整理として参照）。

腕の勘定：炭素1個と酸素2個で12本 ＝ つないだ腕8本 ＋ 埋まった腕4本（どれも酸素の側）

| | 共有 | つないだ腕 | 埋まった腕 | 炭素に残る腕 |
|---|---|---|---|---|
| CO | 面1枚 | 6 | 2 | **埋まった腕が1本** |
| CO₂ | 辺2本 | 8 | 4 | なし |

同じ炭素と酸素でも、つなぎ方が違うと、炭素に残る腕が違います。

## 8. 一酸化炭素はなぜ危険なのか

**図6：二酸化炭素 CO₂ ― 向かい合う二辺で腕を使い切る**（Bond6 co danger.html）
@[codepen](https://codepen.io/editor/morcb13-bit/pen/01a137d3-1c96-74a8-821c-40f6499f0d5a?default-tab=result)

血液の中で酸素を運ぶのは、ヘモグロビンの中心にある鉄です。鉄の上には席が一つ空いています（観察者側の整理として参照）。

模型の上で、この席に乗る二つの分子を比べます。

- **O₂**：二つの酸素が辺を共有した形。埋まった腕は分子の軸から斜めに出ている。鉄の席には斜めに乗り、体のすみずみで離れて渡される
- **CO**：炭素の埋まった腕が、分子の軸の上をまっすぐ外へ向いている。鉄の席にまっすぐ差し込まれ、鉄・炭素・酸素が一直線に並ぶ

CO は鉄に炭素の側で結びつき、鉄・炭素・酸素はほぼ一直線になること、O₂ は折れ曲がって結びつくこと、CO が酸素より強く結びついて離れにくいことは、記録として知られています（観察者側の整理として参照）。模型で炭素に残った「まっすぐ外を向く埋まった腕」は、この並び方と同じ向きを持っています。

CO が居座った席には酸素が乗れず、運ばれる酸素が減っていきます。CO₂ では炭素の腕4本がすべて酸素とつながっていて、鉄の席へ差し込む腕が炭素に残りません。

## 9. 記録との照合

模型を平衡構造の記録と照合しました。判定は整数の比較だけで行い、基準は走らせる前に決めています。順序を入れ替えた模型（三重結合が一番長い）は NG に、記録そのものから作った比は OK になることを先に確かめ、判定器が両方の答えを返せることを確認しました。

| 照合したこと | 模型 | 記録 | 判定 |
|---|---|---|---|
| 長さの順 C–C > C=C > C≡C | 頂点 > 辺 > 面 | 1.522 > 1.3305 > 1.20289 Å | OK |
| 長さの順 CO < CO₂ | 面 < 辺 | 1.1283 < 1.160 Å | OK |
| エチレンの H 4個が一平面 | 法線 (0, 72, 72) | 平面分子 | OK |
| アセチレン・CO₂ が一直線 | 外積 0・中心の和 0 | 直線分子 | OK |
| 鉄との角の順 Fe–C–O > Fe–O–O | 180° > 125.26° | 171° > 156° | OK |
| 長さ² の比 9 : 3 : 1 | 単:二 ＝ 3、二:三 ＝ 3 | 約 1.31、約 1.22 | NG |
| エチレンの角 H–C–H・H–C–C | 109.47°・125.26° | 117.10°・121.45° | NG |

形（平面か一直線か）と並びの順は、共有する場所だけで決まり、記録と一致します。長さの比と角の値は、共有する場所だけでは決まりません。記録の長さは模型よりずっと詰まっていて、それを書くにはもう一つ次元を足した読みが要ります。この一般化は次の回以降に回します。

その2では、イオン結合と金属結合を同じ正四面体で描き、なぜ金属だけが金属結合になるのかを図で見ます。

## まとめ

立方体の一つおきの頂点で組んだ正四面体を、頂点・辺・面で共有させると、単結合・二重結合・三重結合が整数の座標のまま組めます。中心どうしの長さ² は 108 : 36 : 12 と 3 で割れていきます。空いた頂点は、頂点共有では互い違い、辺共有では一枚の平面、面共有では一直線に並び、エタン・エチレン・アセチレンの形になります。

同じ数え方で、水素のいない CO と CO₂ を比べると、残る腕が違います。CO₂ では炭素の腕4本がすべて酸素とつながります。CO では炭素に、軸の上をまっすぐ外へ向く埋まった腕が1本残ります。この腕が、ヘモグロビンの鉄の席をふさぐ向きです。

記録と照合すると、形と並びの順はすべて一致し、長さの比と角の値は一致しませんでした。

**共有結合は、正四面体が頂点・辺・面のどれを共有するかで、出会う腕の数と残る腕の向きが決まります。**
