# 検定 FR3 事前登録（2026-10-15、実行前に凍結）

## 見立て（今日の図から）
- 2 で割る段の骨組みは A だけ。3 で割る段の骨組みには、中心に鏡像 B が入り、A と辺を分け合う
- n−1 殻に埋まった d を持つ元素（第 4 周期以降の 13〜17 族）を「骨組みに B を持つ元素」X とする［X の範囲は知識：Ga 以降の p ブロックは 3d が埋まっている］
- X：Ga Ge As Se Br In Sn Sb Te I Tl Pb Bi Po At

## 規則 FR3（固定）
- X でない元素：FR と同じ（v ≤ 3 なら出す側 D、それ以外は分け合う側 S）
- X の元素：出すことも分け合うこともできる。手数の少ない方を取る：v＋v ≤ 8 なら D、それ以外は S
- 単体：D → 金属、S → 共有
- 二元化合物：D＋D → 金属、S＋S → 共有、D＋S → D の原子が X なら共有（辺で分け合う）、X でなければイオン
