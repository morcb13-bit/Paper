# 検定 SH 事前登録（2026-10-15、実行前に凍結）

## 仮説
- 部品は 2×2 の割り方と 3×3 の割り方の 2 種類だけ
- 規則 NEST（入れ子）：n が 2 と 3 の掛け合わせ（n＝2^a·3^b、n＝1 を含む）なら、殻 n は満杯（2n²）まで埋まる。それ以外は満杯にならない

## 照合する記録（知識。検算していない）
- 元素 1〜118 の基底状態で、各殻に入る電子の最大数
  - n＝1：2（満杯）　n＝2：8（満杯）　n＝3：18（満杯）　n＝4：32（満杯）
  - n＝5：32（容量 50、満杯でない）　n＝6：18（容量 72、満杯でない）　n＝7：8（容量 98、満杯でない）
- 対象は n＝1〜7 の 7 殻。正答は「満杯か、満杯でないか」の一致数

## 対照
- 規則 ADD（並べる）：n＝1 か、n＝2a＋3b と書ければ満杯（n＝1〜7 はすべて満杯と予言）
- 負の対照：n＝1〜7 から、NEST が満杯と予言する個数と同じ個数をくじで選んで「満杯」とする。全通り（組み合わせの全部）を数える

## 判定（整数の比較）
- OK：NEST の正答数が ADD より 2 以上多く、かつ負の対照の平均より 2 以上多い（通り数·NEST ≥ 負の対照の総和 ＋ 2·通り数）
- NG：上の条件を満たさない
- 申告：殻は 7 つしかなく、検定としての力は弱い。n＝6・7 が満杯にならないのは、元素が 118 で止まっていることにもよる（模型の外の理由）
