# 検定 FR 事前登録（2026-10-14 11:10 JST、実行前に凍結）

## 三つの層
- 幾何学的な見立て：枠（正四面体 A と鏡像 B、席 8）どうしが点・辺・面で接する
- 化学的な分類：記録上、物質がイオン・共有・金属のどれとされるか（単体は金属／非金属）
- 検定する仮説：枠の席の空き具合から出した予言が、化学的な分類と再現性をもって対応するか

## 予言規則（固定）
- 入力：外側の殻の電子 v（典型元素の族から。1族 1、2族 2、13族 3、14族 4、15族 5、16族 6、17族 7）
- 出す側 D：v ≤ 3 ／ 分け合う側 S：4 ≤ v ≤ 7
- 単体：D → 金属、S → 共有（非金属）
- 二元化合物：D＋D → 金属、S＋S → 共有、D＋S → イオン
- 対象外：水素・ヘリウム（第1周期）、18族、遷移元素（d 殻の席は枠で決めていない）

## 対照
- 基準線：すべて「共有」と予言
- 負の対照：採点対象に現れる元素の v をくじ引きで並べ替え（単体と化合物で同じ並べ替えを使う）、規則をそのまま当てる。乱数のシード 13、試行 10,000 回。平均・最小・最大・分布を記録

## 判定（整数で比較）
- OK：合計の正答数 FR が、基準線より 3 以上多く、かつ負の対照の平均より 3 以上多い（10000·FR ≥ 負の対照の総和 ＋ 30000）。単体・化合物の内訳を報告する
- NG：上の条件を満たさない
- 判定不能：上の表で判定不能とした物質。OK・NG とは別に数える
- 併記（判定には使わない）：10,000 回のうち負の対照が FR 以上を取った回数
- OK は「この対象群で、固定した規則が二つの対照を上回った」という意味に限る

## 実行前に予想される外れ（記録を知っているための申告）

- 化合物の BN・GaAs（13族と15族の組。規則は D＋S でイオンと予言する）
