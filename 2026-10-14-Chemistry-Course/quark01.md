## 1. 三次元のギャスケットで数える

まず三次元で試しました。3 段の星型ギャスケット（正四面体 A と、その鏡像 B を重ねたもの）の頂点に、次の読みを置きます。

- **色**：3 つの座標のうち、ほかの二つと違う一つの位置（x, y, z の 3 方向 ＝ 3 回軸のまわりの 3 方向）
- **電荷**：座標の和（3 回軸に沿った高さ）

色を一つずつ使う三点組のうち、ギャスケットを作る小さな正四面体の**面**になっているものを数えました。

| 組 | 電荷の並び | 三点組 | 面になったもの |
|---|---|---:|---:|
| Δ⁺⁺ (uuu) | 2, 2, 2 | 1 | 1 |
| 陽子 (uud) | 2, 2, −1 | 9 | **0** |
| 中性子 (udd) | 2, −1, −1 | 27 | **0** |
| Δ⁻ (ddd) | −1, −1, −1 | 27 | 3 |

【計算】

u だけ、または d だけの組は面になります。u と d が混ざった陽子・中性子は、一つも面になりません。

u の点は A 側に、d の点は B 側に集まっています。混ざった組は二つの正四面体にまたがるので、どちらの正四面体の面にもなりません。三次元の中では、ここで行き止まりです。

**図1：　3 段の星型ギャスケット**　(s1_gasket_3d.png)
![](https://static.zenn.studio/user-upload/afc3e6ab8bf0-20261115.png)
実線の uuu は A の面、点線の uud はどの正四面体の面でもない]

## 2. 一つ上の次元に置く

立方体は、正四面体 A と B を重ねた形です。そして、正十六胞体（4 次元の 8 頂点 ±e₁…±e₄）を対角線 (1,1,1,1) の方向から見た影が立方体になります。つまり、三次元で重なっていた A と B は、四次元では離れて置かれていることになります【計算】。

そこで、一つの世代の 8 つの状態を、正十六胞体の 8 頂点に置きます。

| | 軸 1 | 軸 2 | 軸 3 | 軸 4 |
|---|---|---|---|---|
| + 側 | ν | u（赤） | u（緑） | u（青） |
| − 側 | e | d（赤） | d（緑） | d（青） |

- 軸 1 をレプトン、軸 2〜4 を 3 色にする
- 符号の + を上の型、− を下の型にする

電荷は、符号 s（±1）と軸の数 c だけで決めます。c はレプトンの軸で −3、色の軸で +1 です。

```python
def q(i, s, bar=0):                 # i: 軸 0..3, s: ±1, bar: 反粒子なら 1
    c = -3 if i == 0 else 1
    if bar: c = -c                  # 反粒子は c の符号だけ反転
    return (3*s + c) // 2           # 1/3 単位の電荷
```

8 頂点の電荷は ν 0、e −3、u +2（3 色）、d −1（3 色）になります。どれも割り切れる整数です【計算】。

正十六胞体の頂点は、**反対側の頂点（対蹠）とだけ**辺で結ばれていません。ほかのすべての頂点とは辺で結ばれています。

```python
adj = lambda a, b: a[0] != b[0]     # 同じ軸の ± どうし以外はすべて辺
```

## 3. 陽子と中性子が面になる

走らせる前に、次の三つを基準として決めました。

- H1：8 頂点の電荷が、上の値にちょうどなる
- H2：色を一つずつ使う三点組（8 通り）が、すべて正十六胞体の面になる
- H3：その面の電荷の和が 6, 3, 0, −3 に並び、陽子型と中性子型は 3 通りずつになる

| 組 | 面の数 | 電荷の和 |
|---|---:|---:|
| Δ⁺⁺ (uuu) | 1 | 6 |
| 陽子 (uud) | 3 | 3 |
| 中性子 (udd) | 3 | 0 |
| Δ⁻ (ddd) | 1 | −3 |

【計算】 正十六胞体の三角形の面は 32 枚あります。そのうち 8 枚が、色を一つずつ使う組です。三つの基準はすべて満たされました。

三次元で面にならなかった陽子と中性子も、四次元では面になります。u の頂点と d の頂点は、軸が違えば必ず辺で結ばれるからです。

## 4. 反粒子は同じ頂点のもう一つの席

反粒子は、c の符号だけを反転して、**同じ頂点のもう一つの席**に置きます。

| 頂点 | 席 1 | 席 2 |
|---|---|---|
| +e₁ | ν (0) | ē (+3) |
| −e₁ | e (−3) | ν̄ (0) |
| +e₂…₄ | u (+2) | d̄ (+1) |
| −e₂…₄ | d (−1) | ū (−2) |

【計算】 8 頂点 × 2 席 ＝ 16 状態になり、電荷はすべて整数で合います。

ギャスケットの継ぎ目に A 側と B 側の 2 席を数えたのと同じ数え方です【見立て】。

## 5. メソンは辺に乗らない組

同じ色の軸から q と q̄ を一つずつ取ると、二つは**同じ頂点**か**対蹠**に落ちます。

| 組 | 置き場所 | 電荷 |
|---|---|---:|
| u d̄ （π⁺） | 同じ頂点 | +3 |
| d ū （π⁻） | 同じ頂点 | −3 |
| u ū | 対蹠 | 0 |
| d d̄ | 対蹠 | 0 |

【計算】 色の違う q q̄ は、例外なく辺に乗ります。対照として数えたこの組と、色が打ち消し合う組とで、置き場所が入れ替わることはありませんでした。

正十六胞体で辺に乗らない組は、同じ頂点か対蹠しかありません。色が打ち消し合うメソンは、ちょうどその場所を使っています。

## 6. 整数の電荷になるのは、色が打ち消し合う組だけ

面 32 枚と胞 16 個のすべてについて、「色が打ち消し合うか」と「電荷が 3 の倍数（整数電荷）か」を並べました。

| 形 | 色が打ち消し合う | 整数電荷 | 数 |
|---|---|---|---:|
| 面（レプトンの軸を含む） | いいえ | いいえ | 24 |
| 面（3 色） | はい | はい | 8 |
| 胞（レプトン 1 個 ＋ 3 色） | はい | はい | 16 |

【計算】 食い違いは 0 件でした。

レプトンの軸を含む面には 2 色ぶんのクオークしか乗らないので、電荷は 3 の倍数になりません。胞はレプトン 1 個とバリオン 1 組を合わせた形で、電荷は整数になります。

## 7. 三つの世代の置き場所

正十六胞体 8 頂点と正八胞体 16 頂点を合わせると、正二十四胞体の 24 頂点になります。その中に、互いに頂点を共有しない正十六胞体がいくつあるかを数えました。

| 立体 | 頂点 | 内接する正十六胞体 |
|---|---:|---:|
| 正二十四胞体 | 24 | **3** |
| 正八胞体（対照） | 16 | 2 |

【計算】

## つながり

- レプトンを 4 つ目の色として 4 本の軸に並べる置き方は、Pati–Salam の組み方と同じ形です【知識】。電荷の式 (3s + c)/2 は、Q = T₃R + (B−L)/2 の形に当たります【知識】。
- 正二十四胞体が三つの正十六胞体に分かれることは、四元数の側では三対性として知られています【知識】。

この記事では、どちらも説明の根拠には使っていません。整数で数えた結果を、既存の言葉に当てるとこうなる、という対応を示すだけです。

## まとめ

三次元のギャスケットでは、u と d が正四面体 A と B に分かれて重なっていました。そのため、混ざった組である陽子と中性子は面になりませんでした。

一つ上の正十六胞体に置くと A と B が離れ、次のように並びました。

- 色が打ち消し合う 8 組（Δ⁺⁺、陽子型 3、中性子型 3、Δ⁻）は、すべて三角形の面
- 反粒子は、同じ頂点のもう一つの席
- メソンは、辺に乗らない組（同じ頂点か対蹠）
- 整数の電荷になるのは、色が打ち消し合う組だけ
- 世代の数は、正二十四胞体の中の正十六胞体の数と同じ 3

どれも頂点・辺・面を数えた整数です。質量はまだ扱っていません。
