## 前回までのあらすじ

前回の記事で、平面のペンローズタイリングを**高次元の格子の影**として見ました。5次元の整数格子を用意し、それを平面（実空間）と残りの3次元（残渣空間）に分け、残渣側に置いた**窓**の中に落ちた点だけを採る。窓は正五角形でした。カット・アンド・プロジェクト法です。

この組み立ては、次元を上げてもそのまま通ります。**変わるのは窓だけ**です。

| | 2次元 | 3次元 | 4次元 |
|---|---|---|---|
| 担体の次元 | 5 | 6 | 8 |
| 実空間 ＋ 残渣 | 2 ＋ 3 | 3 ＋ 3 | 4 ＋ 4 |
| 窓 | 正五角形 | 菱形三十面体 | 600胞体 |
| 窓の頂点数 | 5 | 32 | 120 |
| 対称の位数 | 10 | 120 | 14400 |

担体の次元が 5 → 6 → 8 と、1ずつでないのが目を引きます。今回はこの梯子を立体（3次元）に上げたところで実際に起きたことと、そこで手に入れた道具の話です。

---

## 立体に上げて、最初に困ったこと

立体で作りたかったのは、**菱形三十面体を面どうしで繋いだ輪**です。Kabai と Bérczi の『Rhombic Structures』に、この輪を積んで管にした図があります。

輪が閉じるかどうかは二択です。閉じるか、閉じないか。「だいたい閉じる」という状態はありません。

ところが、回転を教科書どおりに書くと、こうなります。

```
Q = (cos(θ/2); α·sin(θ/2), β·sin(θ/2), γ·sin(θ/2))
回転後 = Q P Q̄
```

これで15個ぶん繋いで元の位置に戻ったかを見ると、返ってくるのは

```
(0.9999999999999998, 2.7e-16, -1.1e-16, 4.4e-16)
```

のような数です。**閉じたのか、閉じていないのか、これでは言えません。**

もちろん `abs(x - 1) < 1e-9` と書けば「閉じた」と言えます。ただそのとき、私は何を確かめたことになるのでしょうか。1e-9 を 1e-12 にしたら結論が変わるなら、それは幾何を測ったのではなく、閾値を測っています。

実際に痛い目を見ています。私は以前、3次元の計算で**面法線を取り違えたまま**最後まで走らせたことがあります。外接／内接の比が 1.018 というありえない値が出ていたのに、浮動小数と許容誤差の中では全部「合格」で通っていました。φ の厳密な演算に移して、等号で検算した瞬間に露出しました。

**欲しかったのは精度ではなく、等号でした。**

そして、**20面体対称に限れば、三角関数を一度も呼ばずに厳密な回転が書けます。**以下がその手順です。

---

## 使う道具：単位イコシアン120個（借用）

まず借りものの説明から。

四元数のうち、成分が黄金比 φ = (1+√5)/2 を係数に持つ半整数で、長さが1のものを集めると、**ちょうど120個**になります。これを単位イコシアンと呼びます。内訳は次の3種類です。

- `½(±2, 0, 0, 0)` の偶置換 …… 8個（＝ ±1, ±i, ±j, ±k）
- `½(±1, ±1, ±1, ±1)` …… 16個
- `½(0, ±1, ±1/φ, ±φ)` の偶置換 …… 96個

合計 120。この120個は、4次元の正多胞体である**600胞体の頂点**そのものです。そして掛け算で閉じています ── どの2つを掛けても、また120個のどれかになる。図形であると同時に群だということです。

ここまでは Conway と Sloane、Conway と Smith による古典的な内容で、私の発見ではありません。出典は末尾に置きます。

### なぜ φ が出てくるのか

回転四元数の実部は cos(θ/2) でした。20面体の回転で使う角は 72°, 120°, 144°, 180° です。この cos(θ/2) を並べると、

| θ | cos(θ/2) |
|---|---|
| 72° | φ/2 |
| 120° | 1/2 |
| 144° | (φ−1)/2 |
| 180° | 0 |

**全部 φ の半整数です。**三角関数が消えるのはこのためで、偶然ではありません。20面体対称の回転角は、cos が φ の整数式で書ける角しか含まないのです。

## 実装

φ を含む数を、有理数2つ `a + bφ` として持ちます。`φ² = φ + 1` だけ知っていれば掛け算ができます。

```python
from fractions import Fraction as F

class Q5:
    """a + b·φ。φ² = φ + 1。"""
    def __init__(self, a=0, b=0):
        self.a, self.b = F(a), F(b)
    def __add__(s, o): return Q5(s.a+o.a, s.b+o.b)
    def __sub__(s, o): return Q5(s.a-o.a, s.b-o.b)
    def __mul__(s, o):
        return Q5(s.a*o.a + s.b*o.b,
                  s.a*o.b + s.b*o.a + s.b*o.b)
    def __eq__(s, o): return s.a == o.a and s.b == o.b
    def __hash__(s):  return hash((s.a, s.b))
```

四元数はこれを4つ並べただけです。積の規則は通常どおり。

```python
class H:
    def __init__(self, c): self.c = tuple(c)
    def __mul__(s, o):
        a1, b1, c1, d1 = s.c
        a2, b2, c2, d2 = o.c
        return H((a1*a2 - b1*b2 - c1*c2 - d1*d2,
                  a1*b2 + b1*a2 + c1*d2 - d1*c2,
                  a1*c2 - b1*d2 + c1*a2 + d1*b2,
                  a1*d2 + b1*c2 - c1*b2 + d1*a2))

def conj(q):
    z = Q5(0, 0)
    return H([q.c[0], z-q.c[1], z-q.c[2], z-q.c[3]])

def rotate(q, p):
    return (q * p) * conj(q)      # サンドイッチ
```

点は実部を0にした四元数 `(0; x, y, z)` として渡します。`math` を import していないことに注意してください。**この回転には三角関数も浮動小数も出てきません。**

## 検定

出す前に、何が出たら合格かを決めておきます。

| | 何を見るか | 合格の条件 |
|---|---|---|
| 検定1 | サンドイッチの実部 | 全120回転×全頂点で**厳密に 0**（近似の0ではない） |
| 検定2 | 長さ | 回転前後で厳密に等しい |
| 検定3 | 回転の個数 | q と −q が同じ回転なので **60通り** |
| 検定4 | 表せる角度 | **単位**イコシアンでは θ ∈ {0°, 72°, 120°, 144°, 180°} |
| 検定5 | 誤差 | 10万回合成して戻して、ずれが厳密に 0 |

正20面体の12頂点に対して回してみた結果です。

```
検定1  120回転 × 12頂点 のうち実部が0でないもの 0        → OK
検定2  ノルムが変わったもの 0                            → OK
検定3  相異なる回転 60通り／1通りあたり四元数2個（q と −q）→ OK
検定4  θ の分布 {0:1, 72:12, 120:20, 144:12, 180:30, …}   → OK
検定5  20万回合成して戻す：整数版のずれ 0（厳密等号）      → OK
       対照：同じ手順の浮動小数版のずれ 2.220e-15
おまけ 正20面体が自分に写らなかった対 0 / 1440           → OK
```

72°回転を実際に5回かけると、こうなります。

```
Q = (φ/2 ; −1/2, 0, (φ−1)/2)
P = (0, 1/2, φ/2)

1回目 → (−1/2,  φ/2,   0  )
2回目 → (−φ/2,  0,   −1/2 )
3回目 → (−1/2, −φ/2,   0  )
4回目 → ( 0,   −1/2,  φ/2 )
5回目 → ( 0,    1/2,  φ/2 )   ← 元に戻る（厳密）
```

「5回目で戻った」は、丸めた結果が一致したのではなく、**分数として同じ**です。

## 平衡φ進数のほうが優位な点

正直に言うと、**精度の問題ではありません。**対照実験で浮動小数版のずれは 2.2×10⁻¹⁵ でした。20万回合成してこれなら、描画用途では困りません。

問題は別の2点です。

### 1. 等号で判定できる

これが本命です。次のような問いが、そのまま書けるようになります。

- この輪は閉じるか（閉じる／閉じないの二択）
- この立体は自分自身に写るか
- この2つの図形は φ 倍の相似か

許容誤差を置くと、これらは全部「だいたい」の話になります。そして冒頭に書いた面法線の取り違えのように、**許容誤差の中に隠れた誤りは、精度を上げても出てきません。**桁を増やしても、閾値の内側にいるかぎり合格し続けます。等号にすると、その日のうちに落ちます。

### 2. 状態が有限

単位イコシアンの積は、必ず単位イコシアンです。つまり**何万回合成しても、状態は120個の中から出ません。**桁が増えず、正規化も要らない。回転を「120元の群の元」として持てるということです。番号1つで回転が表せます。

（次節で段を下げるとノルムは増えますが、それでも増えるのは整数の大きさであって、誤差ではありません。）

---

## 精度は「桁」ではなく「深さ」で上げる

ここまで使ったのは**単位**イコシアン120個だけでした。長さ1のものに限ると回転は60通りで、角度は5種類しかありません。

「では任意の角は回せないのか」と思うところですが、**そうではありません。**

長さ1という縛りを外し、120個の**整数の和**まで許すと、それはイコシアン環と呼ばれる環になります。この環は四元数の中で**稠密**です。そして単位でない四元数 q でも、ノルム N = q q̄ で割れば回転になります。N は Z[φ] のただの数なので、**割っても Q(√5) の外へ出ません。厳密さは保たれます。**

実際にやってみると、こうです。段を1つ下げるとは、120個の元をもう1つ足すという意味です。

| 段 | 最小の非ゼロ回転角 |
|---|---|
| 1（単位のみ） | 72.000000° |
| 2 | 36.000000° |
| 3 | 13.290744° |
| 4 | 8.772355° |
| 5 | 6.264301° |
| 6 | 3.929257° |
| 7 | 2.807151° |

刻みは細かくなり続けます。しかも**どの段でも、成分は φ の有理係数のまま**です。段2の例で確かめると、

```
q = (−3/2 ; −φ/2, (φ−1)/2, 0)     ノルム N = 3
実部が厳密に 0 か        → True
|回転後| = N²·|元| か     → True
```

平衡φ進数を使うと浮動小数はどこにも出てきません。

これが浮動小数の精度と決定的に違うところです。浮動小数で精度を上げるとは、**仮数の桁を増やす**ことで、増やしても誤差はゼロになりません。ここで精度を上げるとは、**段を下げる**ことです。段を下げると刻みが細かくなり、**各段では誤差がゼロのまま**です。同じ120個の元を足し続けるだけなので、細かくする手続き自体も自己相似です。

代わりに払う代金は、桁ではなく**ノルムの成長**です。段を下げるほど N が大きくなり、扱う整数が大きくなります。誤差と付き合うか、整数の大きさと付き合うか、という交換になります。

### 精度は注文できる

角の細かさとノルムの関係は θ ≈ 2/√N なので、逆に解けます。**必要な精度から、要る整数の大きさが決まります。**

| 用途 | 要る角度分解能 | ノルム N | 整数の桁数 |
|---|---|---|---|
| 画面表示（4Kの1画素ぶん） | 2.7×10⁻⁴ rad | 10⁷·⁷ | 8桁 |
| マシン精度（double 相当） | 10⁻¹⁶ rad | 10³² | 32桁 |
| プランク長／観測可能宇宙 | 1.8×10⁻⁶² rad | 10¹²⁴ | 124桁 |

124桁の整数は、Python なら何の苦もなく扱えます。**上限はありません。**

面白いのはここからで、これを実演しようとすると、**角度を表示する側が先に壊れます。**

```
q = (m ; −1, 0, 0)      ← 整数 m を足しただけのイコシアン

m = 10⁶   → θ = 2.000e-06 rad   （math.acos で出る）
m = 10⁸   → θ = 0.000e+00 rad   ← 印字できない
m = 10⁶²  → θ = 0.000e+00 rad   ← 印字できない
```

`math.acos` は 10⁻⁸ の手前で飽和します。しかし四元数そのものは `(10⁶²; −1, 0, 0)` という整数のまま正確にそこにあり、回転として使えば厳密に効きます。**測る側が先に潰れるだけで、対象は潰れていません。**

これが「桁を増やす」と「段を下げる」の違いです。浮動小数は仮数の底が抜けたところで止まりますが、整数は止まりません。

本当の制約は角度ではなく、**対象が20面体対称に乗っているかどうか**です。準結晶、ウイルスのカプシド、フラーレン、測地線ドーム ── そういう構造を扱うときに、この道具は効きます。

## 冒頭の問いに戻る

最初の問い ── **菱形三十面体の輪は閉じるのか。**

答えは出ました。**5個・10個・15個で閉じます。**成立する繋ぎ方はそれぞれ 10通り・90通り・1230通りです。

判定はこうなりました。菱形三十面体を面で繋ぐ一歩は、6次元では「±1 が4つ・0 が2つ」の整数ベクトルになります。すると、

> **輪が閉じる ⟺ 使った一歩の総和が6次元でちょうど 0**

これは整数の足し算です。丸めも閾値も入りません。閉じるけれども立体としては食い込んでしまう組み方も1390件あり、そちらは別に弾いています（判定は支持関数で、これも厳密）。

この道具で、ついでに出た結果を2つ。どちらも「ちょうど一致するか」を訊いた問いで、許容誤差を置いていたら答えが出なかったものです。

**輪を積むとらせんになる。**面接触を保ったまま真上に積むことはできません。接触を残す積み方は必ず横にずれます。ところがその横ずれは、1層ごとに72°まわるので**5層でちょうど相殺します**。5層ぶんの並進は、6次元の整数ベクトルとして横成分が厳密に 0。らせんのピッチは **4 + 12φ = 23.416407865** で、これも厳密値です。

**600胞体の中に相似がある。**4次元の窓である600胞体を4番目の座標で切ると、断面は 点 → 正20面体 → 正12面体 → 正20面体 → 12・20面体 と変わります。2枚ある正20面体の断面は半径 0.587785 と 0.951057 で、**比がちょうど φ**。しかも向きまで同じで、内側を φ 倍すると外側にぴったり重なります（最大ずれ 1.1×10⁻¹⁶ ＝ 機械のゼロ）。

平面のペンローズで「図形の上に同じ図形が重なって見える」と感じていたものの出どころが、**窓の側にあった**ということになります。窓が自分の φ 倍を含んでいるなら、そこから切り出した図形に自己相似が出るのは当然です。

## 倒れる条件

次のどれかが示されたら、この記事は倒れます。

1. サンドイッチ q P q̄ の実部が0にならない回転が、120個の中に1つでもある
2. 相異なる回転が60通りより多い、または少ない
3. {0°, 72°, 120°, 144°, 180°} 以外の角が、**長さ1の**イコシアンで表せる
4. 単位イコシアンどうしの積が、120個の外に出る

1〜4 はどれも有限個の確認で、コードを走らせれば数秒で決着します。私は全部走らせて、全部 OK でした。走らせずに信じないでください。
