これは方程式ではありません。オートマトンです。

解くものではなく、走らせるものです。局所の状態から局所の次の状態を決める規則が一つあり、それを全体に一斉に当てる。それだけでできています。

実行規則に使うのは、整数の足し算、整数倍、符号の反転だけです。割り算も、小数も、虚数も、乱数も入りません。記事の後半では、走らせた結果の周期を調べるために固有値を使います。装置を動かす側と、動いたものを解析する側は、別のものとして読んでください。

上の図が装置そのものです。平たい網がペンローズタイリングの一部、立っている柱が状態です。ドラッグで回せます。

## 担体

網の側から説明します。

五角形を10枚、輪にしたものを一つ取ります。これで頂点が30個、辺が40本。辺には向きがあるので、状態が乗る場所は80か所です。

頂点は状態を持ちません。**状態は辺に乗ります。** 図の柱が一本ずつ、その80か所の整数です。

30個の頂点のうち、20個は隣が3つあり、10個は隣が2つしかありません。図で黄色く塗ってあるのが後者です。あとで効いてきます。

## 一歩

規則はこれだけです。

```
S_v = ψ(u→v) の、v に入ってくるぶん全部の合計
ψ'(v→u) = c(d_v)·S_v − 12·ψ(u→v)
```

頂点ごとに入ってきたものを合計し、それを出口へ配り、自分が来た分を12倍して引く。以上。

**係数は選んでいません。** 引く側を12倍と決めた時点で、配る側 `c(d)` は `24/d` しかありません。次数2で12、3で8、4で6。展開すると

```
Σ(cS − 12x_i)² = (d c² − 24c)S² + 144 Σx_i²
```

で、第一項が消える条件が `d c² = 24c`、つまり `dc = 24`。ここから同時に二つ出ます。

- **二乗和は毎歩ちょうど144倍になる**（次数によらず）
- **一歩が逆にたどれる**。出た側の合計が `(dc − 12)·S_v = 12·S_v` なので、出た分だけから入った分が戻る

144倍則と可逆性が、別々の要請ではなく同じ一つの条件から出ます。二乗和そのものが保たれるのではありません。毎歩きっかり144倍になる、という意味です。`c` を ±1 でもずらすと、どちらも壊れます。

そして担体に条件が一つ付きます。**次数が 24 を割ること。** 次数5や7の頂点がある網では、この一歩を整数で書けません。ペンローズの円環に出る次数は 2・3・4 で、全部 24 を割ります。

## 井戸

この装置に「深さ」を足す場所はありません。位置エネルギーに当たる項を足すと `dc = 24` が崩れ、可逆性が消えます。

では何が閉じ込めるのか。**網の切れ目です。**

次数2の頂点（図の黄色）には、先へ進む辺が存在しません。壁がそこにあるのではなく、そこから先が無い。だから壁です。深さは選べません。この装置に作れる井戸は、無限に深いものだけです。

## 檻の大きさ

12で割り戻す形が要るので、剰余 `m` を取ります。条件は `gcd(m, 12) = 1` だけ。剰余を取ると状態は有限個になり、一歩が可逆なので、必ず巡って戻ってきます。

戻るかどうかは問いになりません。可逆性から出ます。測るべき整数は、何歩で戻るかです。

一本の辺に 1 を置いて始めると、

| 剰余 m | 一周 |
|---:|---:|
| 5 | 1560 |
| 7 | 9882600 |
| 11 | 108065160 |
| 13 | 5859189829080 |
| 17 | 205169328 |
| 19 | 424647720 |
| 23 | 39155492640 |

図の剰余を切り替えると、5 のときは画面の中で戻ってきます。13 にすると一周が5兆歩を超えるので、二度と戻りません。同じ井戸で、割り戻し方を変えただけです。

## 一周が担体のどこから出るか

80本の辺を追う必要はありません。**30個の頂点だけで決まります。**

頂点の上を歩く行列（隣接を次数で割ったもの）の特性多項式は30次で、こう割れます。

```
μ − 1
μ
9μ² + 3μ − 4
9μ² + 6μ − 1
324μ⁶ − 108μ⁵ − 378μ⁴ + 102μ³ + 109μ² − 25μ − 5
324μ⁶ + 108μ⁵ − 270μ⁴ −  66μ³ +  49μ² +   μ − 1
```

辺の側の一歩とは `x² − 24μx + 144` で結ばれていて、この6本から辺の側の因数が過不足なく出ます。あとは剰余 m でそれぞれの位数を取り、最小公倍数を作るだけ。

1560 の中身はこうです。

```
1560 = 312 × 5
  312 = lcm(1, 4, 24, 52)
   52 = 4 × 13
    5 = m
```

52 の 13 は `9μ² + 6μ − 1` から来ます。この式の根は `μ = (−1 ± √2)/3`。剰余5の世界には √2 が居ないので、この式は割れずに4次のまま残り、位数が 5⁴ − 1 = 2⁴·3·13 を割ることになる。**この 13 は、網の辺数や頂点数を直接数えたものではありません。** 4次因子の根に現れる √2 と、剰余体の算術との関係から出てきます。だから剰余ごとに出たり出なかったりし、実際 11・13・23 では出ません。

最後の 5 も決まります。上の多項式から重複を落とした18次の判別式を m が割るときだけ、m が一回付きます。5・7・17・19 は割り、11・13・23 は割らない。表のとおりです。

図の下の帯が、この6本から出る18個の目盛りです。位置は網が決めていて、式の側から与えたものではありません。黄色い2本が √2 の組です。

## 最後に一度だけ、外と比べる

ここまで外の理論は一つも使っていません。最後に一回だけ出します。

シュレーディンガー方程式の無限に深い井戸も、有限時間で完全に元へ戻ります。同じ現象に見えます。**同じ理由でしょうか。**

向こうの復元は、準位の比が n² で有理数だから起きます。押し込めは要りません。

こちらを調べます。一歩の固有値 `x` を `λ = x/12` に正規化し、`λ` の最小多項式が円分多項式か（＝`λ` が1のべき根か）を、7本すべてについて見ます。基準は先に決めておきます。全部が円分なら、剰余と無関係な有限周期性の可能性が残る。1本でも非円分なら、由来が違う。

| λ の式 | 判定 |
|---|---|
| y − 1 | 円分 Φ₁ |
| y + 1 | 円分 Φ₂ |
| y² + 1 | 円分 Φ₄ |
| y⁴ + (2/3)y³ + (2/9)y² + (2/3)y + 1 | 整数係数にならない |
| y⁴ + (4/3)y³ + (14/9)y² + (4/3)y + 1 | 整数係数にならない |
| 12次（分母 3, 27, 81） | 整数係数にならない |
| 12次（分母 3, 27, 81） | 整数係数にならない |

4本が非円分です。1のべき根は必ず代数的整数なので、分母が残った時点で確定します。

しかも定数項はどれも 1 です。**大きさは 1 のまま、1のべき根ではない。** 回り続けるけれど、同じ向きには二度と戻らない。

分母が3のべきなのは追えます。`λ + 1/λ = 2μ` なので、`λ` が代数的整数であるためには `2μ` がそうである必要がある。`μ` は次数で割った行列の固有値なので、分母に次数が入る。1環の次数は 2 と 3 で、残るのが 3 です。**次数3の頂点があることが、円分から外している当のもの**です。

対照として、配る係数を全部12に壊した設定にも同じ手順をかけました。そちらは定数項が 4 や 16 になり、`|λ| = 1` から外れます。判定の形が違うので、この検査は「何を入れても非円分になる検査」ではありません。

3本は本物です。Φ₁・Φ₂・Φ₄ に当たる部分 ── 全部の辺が同じ値のまま回る場合と、その次に平らな場合 ── は、剰余を取らなくても4歩で向きが戻ります。装置の中にも、向こうと同じ種類の復元を持つ平らな部分はあります。ただ、それだけでは装置全体の復元を説明できません。

## 補足（観察者側の整理）

辺80本から頂点30個へ落とせるのは偶然ではなく、この形の辺作用素の特性多項式が頂点側の行列式に落ちるという既知の恒等式によるものです。名前としてはグラフのゼータ関数の分母にあたります。装置の側からは名前を必要としませんが、大きい担体へ持ち上げるときの道具になります。1245環なら、有向辺64260ではなく頂点21660で書けます。

## おわりに

この装置の復元と、無限井戸の復元は、由来が違いました。向こうは準位の比。こちらは、有限集合と可逆性です。

大きさが保存されることと、有限の周期で閉じることは、別のことでした。装置は二乗和を毎歩144倍に保ちますが、それだけでは戻りません。戻るのは、剰余を取って有限の集合に押し込めたからです。

そして井戸は、式の中ではなく網の中にありました。次数2の頂点で網が途切れている。それが壁です。有限で、可逆で、切れ目がある。閉じ込めは、この三つだけから出ています。
