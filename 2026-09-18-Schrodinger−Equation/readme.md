# 整数だけで動く波の装置

正十二面体の20頂点と、面の対角線60本（五芒星12個ぶん）の上で走る整数の一歩と、その検定一式。

割り算・浮動小数・虚数を使わない。判定は整数の加算と大小比較だけで書いてある。外部依存はなく、Python の標準ライブラリだけで走る。

```
python3 scripts/run_all.py
```

## 装置

**担体** ── 正十二面体の20頂点を `a + bφ` の整数対で置く。二乗距離は二種だけ出る。

```
稜        30本    d² = 8 − 4φ    次数 3   一筆書き 不可
面の対角線  60本    d² = 4         次数 6   一筆書き 可
```

長さの比は `対角線² = φ² · 稜²` として整数対のまま一致する。小数に直す手続きは要らない。対角線の側を担体に使う。向きを付けると `20 × 6 = 120` 本。

**一歩** ── 次数が 6 で一様なので `2L/d = 1`、`L = 3` が取れる。

```
ψ'(u→v) = Σ_{w∼u} ψ(w→u) − 3 · ψ(v→u)
```

係数は `+1` と `−3` の二つだけ。式から割り算が消える。

**保たれるもの** ── `TᵀT = 9I`。二乗和は一歩ごとにちょうど 9 倍。120次元すべてに効く。

**動かない部分** ── 81次元。向きが裏返って `−3` 倍になるだけで場所が動かない。二歩で元の姿に戻る。

**動く部分** ── 39次元。番地ごとの `S`（入る辺の和）と `O`（出る辺の和）に降りる。

```
S' = A·K·S − L·O
O' = L·S
S_{n+2} = A·K·S_{n+1} − L²·S_n
```

**読み出し** ── 判別式 `D = λ² − 4L²` の符号。五芒星グラフの固有値は `6, 2, 1, −2, −3` で、`λ = 6` が `D = 0`（退化して開く）、残り四つが `D < 0`（閉じた楕円）。対 `(s_n, s_{n+1})` がその曲線に乗り、曲線が一歩ごとに `L²` 倍に膨らむ。

**目盛り** ── 起点 `(s_0, s_1)` が `q_0 = q(s_0, s_1)` を決め、それがその番地の 1 になる。種 `(1,1)` からは `4, 8, 9, 12, 13` の五つが出る（`q_0 = 10 − λ`）。種 `(1,0)` では五つとも `9 = L²` に潰れる。単位の違うものは足せない。

**器** ── 平衡13進の桁列。桁は `−6` から `+6` の13種で、符号を別に持たない。内部の操作は加算・桁ずらし・13 の繰り返し減算だけ。乗算も桁倍と桁ずらしの和で作る。

`b13num.py` の `from_int` / `to_int` は入出力（検査と表示）のための変換で、ここだけ Python の整数演算を使う。装置の中の一歩はこれらを呼ばない。繰り上がりは二通り実装してあり、検定B3a で一致を確認したうえで速い側を使う。

## 検定の書き方

各スクリプトの先頭に事前登録がある。測る前に「何が出たら何が言えるか」「NG なら何が言えるか」を書き、そのあとで走らせる。負の対照を入れて、検査が NG を返せることを毎回確認する。

```python
"""
  検定F1  二乗和の一歩
      OK なら：A' = L^2 * A + c(k) * Q が、乱数の psi と複数の (d, k, L) で厳密に成立
      NG なら：式が違う

  検定F4  負の対照
      OK なら：c(k) を正しい値から 1 ずらすと検定F1 の等式が崩れる
      NG なら：検定F1 は NG を返せない検査
"""
```

図も同じ作りにしてある。`figures.html` では曲線を式から描き、点は実際に走らせた数列から打つ。点が曲線から外れたら判定の表示が変わる。

## 主な数値

```
担体            20頂点 / 稜30本 / 対角線60本 / 有向辺120本 / 次数6一様
一歩            L = 3、係数 +1 と −3
TᵀT             対角 9、非対角 0
平衡13進で12歩   単一辺に1  → 9¹² = 282429536481
                 三値を配る → 22311933381999
c(k)            d·k² − 2L·k、根は k = 0 と k = 2L/d
固有値           6, 2, 1, −2, −3（Π(A − λI) = 0 が整数行列として成立）
判別式           0, −32, −35, −32, −27
次元             120 = 81（動かない）+ 39（動く）、39 = 40 − 1
二次形式         q(a,b) = b² − λab + L²a²、一歩ごとに L² 倍
目盛り           q_0 = q(s_0, s_1)。種 (1,1) で 4, 8, 9, 12, 13
```
