## シュレーディンガーの波動方程式を整数だけで描く

---

この記事は、シュレーディンガーの波動方程式を整数だけで描く試みである。

装置の内部から、連続の側の道具を一つずつ外してきた。外したのは三つ。複素数、極限、割り算。

**複素数** ── 役は判別式の符号に移した。`D < 0` の側で対が回る。状態も係数も整数のままになる。

**極限** ── 役は整数の対 `(k, L)` に移した。境界へ近づく操作をやめ、境界の両側を同じ族として書く。

**割り算** ── 役は整数の倍率 `L` に移した。次数が一様なら `L = d/2` で、平均を取ることをやめれば平均は和になる。

平衡13進は、その整数値を運ぶ器になる。桁は `−6` から `+6` で、内部の操作は加算と桁ずらしだけ。複素数の代わりではなく、装置全体を下から支える基盤の側にいる。

三つを外したあとに残っていたのは、目盛りだった。長さの単位が装置の中になければ、一歩の大きさを何にも結べない。この記事の後半で、それが起点にあることを書く。

## 割り算の三つの役

先に外側の整理をしておく。以下は借りた知識で、装置の側から出たものではない。

連続の側で波を書くとき、割り算は三箇所で別々の仕事をしている。

**平均の `1/d`** ── 隣の値の平均から中心を引く。これが場所の広がりを作る。

**規格化の `1/‖ψ‖`** ── 全体の大きさを 1 に戻す。順序としては、先に大きさの測り方を決め、そのあとで時間発展をそれを保つものとして定義してある。保存量は探して見つけたものではなく、初めからそう置いたものになっている。

**極限の `1/Δt`** ── 刻みをゼロへ送りながら同じ速さで拡大し、有限に保つ。

役が違うので、代わるものもそれぞれ別になる。

## 装置の場所

正十二面体の頂点を置く。座標には `a + bφ` の整数対を使う。`φ` を小数にしないので、以下の比較はすべて整数の一致になる。

```
(±1, ±1, ±1)                     8個
(0, ±(φ−1), ±φ) とその巡回        12個
```

20個の頂点の間の二乗距離を全部取って分類すると、二種だけが出る。

```
稜        30本    d² = 8 − 4φ
面の対角線  60本    d² = 4
```

長さの比も整数対のまま出る。`(8 − 4φ) × (1 + φ) = 4` なので、

```
対角線² = φ² · 稜²
```

小数に直して比べる手続きは要らない。

この二種は、つなぎ方として性格が違う。

```
稜の側      次数 3   奇数次数の頂点 20個   一筆書き 不可
対角線の側   次数 6   奇数次数の頂点  0個   一筆書き 可
```

対角線の60本は、五角形の面ごとに5本ずつ引いた五芒星が12個ぶん集まったものになる。以降はこちらを担体として使う。呼び名は五芒星グラフとしておく。

番地は20個、番地あたりの次数は 6。向きを付けると `20 × 6 = 120` 本になる。

## 一歩から割り算が消える

一歩は有向辺の上で書く。番地 `u` に入っている辺の値を集め、そこから来た向きのぶんを引く。

```
ψ'(u→v) = (2L/d) · Σ_{w∼u} ψ(w→u) − L · ψ(v→u)
```

`L` は一歩あたりの倍率で、平均を和に変えるために置く。`d` が一様なら `2L/d` が整数になる `L` が取れて、その最小値は `d` が偶数なら `d/2` になる。

五芒星グラフは次数が 6 で一様なので、

```
2L/d = 2·3/6 = 1,   L = 3
```

つまり一歩は

```
ψ'(u→v) = Σ_{w∼u} ψ(w→u) − 3 · ψ(v→u)
```

になる。**係数は `+1` と `−3` の二つだけで、式から割り算が消える。**

この一歩を120本の有向辺の上で組み、`TᵀT` を直接作ると、対角がすべて 9、非対角がすべて 0 になる。二乗和は一歩ごとにちょうど 9 倍。

平衡13進の桁列のまま12歩走らせても等式は保たれる。単一の辺に 1 を置いた場合の二乗和は `9¹² = 282429536481`、番地に `−1, 0, +1` を配った場合は `22311933381999` で、どちらも加算と桁ずらしだけで出る。

倍率を 1 にできるのは `d ≤ 2` のときだけで、これは枝分かれのない一本道を意味する。**桁が伸びるのは実装の都合ではなく、枝分かれの代金になっている。**

## 何が保たれるか

`L` を最小値から動かすと何が起きるか。`k = 2L/d` を独立なつまみとして、

```
ψ'(u→v) = k · Σ_{w∼u} ψ(w→u) − L · ψ(v→u)
```

と書き直す。`TᵀT` を全成分について調べると、次の形になる。

```
TᵀT = L²·I + c(k)·G
c(k) = d·k² − 2L·k
```

`G` は同じ番地を頭に持つ有向辺の対で 1、他で 0 になる行列。二次形式として読むと、

```
S_u = Σ_{w∼u} ψ(w→u)        番地 u に入る辺の和
Q  = Σ_u S_u²
```

として、二乗和の一歩が整数の漸化式になる。

```
A' = L²·A + c(k)·Q
```

`Q` は二乗和なので負にならない。したがって **伸びるか縮むかを決めているのは `c(k)` の符号だけ**になる。

`c(k)` は `k` についての二次式で、根が二つある。

```
c(k) = d·k·(k − 2L/d)     根は k = 0 と k = 2L/d
```

根の外側で `c > 0`、内側で `c < 0`、根の上で `c = 0`。三つの領域に分かれる。

実際に走らせると、次数3のグラフ（根は 0 と 2）で次のようになる。

```
内側 k=1   6.000, 6.000, 8.000, 8.500, 8.735, 8.859, 8.924, 8.959
根上 k=2   9.000（8歩とも厳密に一定）
外側 k=3   18.000, 18.000, 18.000, 18.000, 22.500, 27.000, 28.800, 30.000
```

一定になるのは根の上だけで、内側も外側も倍率が動く。

図1がこれで、曲線は `c(k)` の式から描き、点は実際に走らせた `ψ` から `(A′ − L²A)/Q` を計算して打ってある。点が曲線から外れたら式のほうが誤りだという作りにしてある。

## 極限を跨ぐ

跨ぐつまみは比になる。

```
s = k·d / 2L
```

根は `s = 0` と `s = 1`。ところが `k` と `L` は独立な整数なので、装置はこの比を計算する必要がない。**対 `(k, L)` を持っているだけで、位置は決まっている。**

次数が偶数のとき、`L` を最小値に取ると根は 0 と 1 で隣り合う。内側に整数がない。`L` を上げると根が離れて内側が開く。

```
d = 6, L = 3    根 0 と 1    内側の整数 なし
d = 6, L = 6    根 0 と 2    k = 1    c = −6
d = 6, L = 9    根 0 と 3    k = 1, 2
d = 6, L = 12   根 0 と 4    k = 1, 2, 3
```

`k=1, L=6` で走らせると倍率は `30.000, 30.000, 35.160, 35.862, 35.973, 35.994, 35.999, 36.000` と `L² = 36` に下から寄る。到達はしない。

これが極限の `1/Δt` に当たる場所になる。連続の側では刻みをゼロへ送って境界に近づくが、こちらは境界の両側を同じ族として書ける。近づく操作が要らない。有理数の `s` は対で全部届き、対で書けない `s` には届かない。

## 番地に降りる

ここまでは120本の辺の上の話だった。番地の側に降ろすと、形が変わる。

番地ごとに二つ取る。

```
S_u = Σ_{w∼u} ψ(w→u)     入る辺の和
O_u = Σ_{w∼u} ψ(u→w)     出る辺の和
```

一歩を代入すると、この二つで閉じる。

```
S' = A·K·S − L·O
O' = L·S
```

`A` はグラフの隣接、`K` は番地ごとの `k_u` を並べた対角。次数が不揃いでも同じ形で立ち、`O'` からは次数が消える。

`O` を消すと `S` だけの式になる。

```
S_{n+2} = A·K·S_{n+1} − L²·S_n
```

整数係数の二階漸化式になる。**辺の上では一階だが、番地の上では二階になる。**

次数が一様な五芒星グラフでは `K` が定数倍なので、固有値ごとに分解できる。隣接の固有値は整数で、

```
6, 2, 1, −2, −3
```

の五つに尽きる（`Π(A − λI) = 0` が20×20の整数行列として成立する）。固有値ごとに

```
s_{n+2} = λ·s_{n+1} − L²·s_n
```

の形になる。

---

## 回転がどこから出るか

この二階漸化式の特性方程式は `x² − λx + L² = 0`。判別式は

```
D(λ) = λ² − 4L²
```

`L = 3` なので `4L² = 36`。五芒星グラフの固有値を入れると、

```
λ =  6   D =   0
λ =  2   D = −32
λ =  1   D = −35
λ = −2   D = −32
λ = −3   D = −27
```

**`λ = 6` だけが 0 で、残りの四つは負になる。**

`D < 0` のとき根は共役な対になり、`(s_n, s_{n+1})` の対が回る。回るために虚数を状態に持つ必要はない。係数も状態も整数のままで、**回転は判別式の符号として構造の側にある。**これが複素数を外した場所になる。

回る半径は `√(L(kd−L))` になる。これが `L` に一致する条件を全組で調べると、

```
kd = 2L   ⟺   L(kd − L) = L²
```

**保存の条件と、半径が `L` に一致する条件が同じものになる。**別々のところから出てきて一致した。

判別式が正の側には、同じ二階の族の別の点が乗っている。`x² − x − 1`、つまりフィボナッチは `D = 5 > 0` で、そちら側にいる。楕円・放物線・双曲線が離心率 1 を境に分かれるのと同じ形で、二階の漸化式も判別式 0 を境に分かれる。装置は境界と負の側を使う。

---

## 対が乗る曲線

対 `(s_n, s_{n+1})` を平面に置くと、整数の二次形式が乗る。

```
q(a, b) = b² − λ·a·b + L²·a²
q(s_{n+1}, s_{n+2}) = L² · q(s_n, s_{n+1})
```

一歩ごとにちょうど `L²` 倍になる。二乗和 `A` の倍率と同じ数で、これも別のところから出てきて一致する。

`q` の判別式は `λ² − 4L²` で、上の `D` と同じもの。したがって曲線の種類が `D` の符号で決まる。五芒星グラフでは

```
λ = 6         D = 0    退化して平行二直線になる。q = (b − 3a)²
λ = 2,1,−2,−3  D < 0    楕円
```

の二種類だけが出る。

図2がこれで、`(s_n, s_{n+1})` を `Lⁿ` で割った点が、決まった曲線の上を跳ぶ。`λ` を切り替えると、楕円が一つだけ平行二直線に潰れる。

ここで図にして初めて見える形が一つある。`λ = 6` の退化は、楕円が細く潰れた形ではない。**開いた形になる。**点は閉じずに直線の上を出ていく。

19次元が閉じた楕円の上を回り、番地に一様な1次元だけが開いて出ていく。二つの振る舞いが同じ装置の中で分かれている。

## 動かない部分

120本の辺のうち、実際に動いているのはどれだけか。

`ψ` から `(S, O)` への写像の階数を調べると 39 になる。40 でないのは `Σ S_u = Σ O_u = Σ ψ` が一本効くため。残りは 81 次元。

その81次元で何が起きているかというと、場所が動かない。

```
S = 0 かつ O = 0 の ψ に対して
ψ'(u→v) = −3 · ψ(v→u)        向きが裏返って −3 倍になる
T² = 9 · I                    二歩で元の姿に戻る
```

倍率のほかは向きの反転だけになる。しかもこの81次元は一歩で保たれるので、他と混ざらない。

```
有向辺              120
向きが裏返るだけ       81
二階漸化式が走る側      39
```

装置を持ち歩くには120本が要るが、動きを追うには39個で足りる。

ここは保存とは別のことを言っている。`TᵀT = 9I` は120次元すべてに効く保存で、81次元は**動かない部分**になる。

## 目盛りは起点にあった

外した三つのあとに残っていたのが、長さの単位だった。一歩の大きさも一辺の長さも、何かに結ばなければ測れない。外から `ħ` や `m` を持ち込めば装置を外の土俵に乗せることになるので、装置の中から出したい。

探す場所を間違えていた。**二階の漸化式は、はじめから起点を二つ要求している。**

```
s_{n+2} = λ·s_{n+1} − L²·s_n
```

これは `(s₀, s₁)` がなければ動かない。そしてその二つが、二次形式の値を決める。

```
q₀ = q(s₀, s₁)
q(s_n, s_{n+1}) = L²ⁿ · q₀
```

**`q₀` がその番地の 1 になる。**以後の歩はすべて `q₀` の倍数として測られ、単位を外から入れる必要がない。5固有値 × 6種 × 12歩の390件で、この等式は厳密に成立する。

起点によって `q₀` が変わる。

```
lambda    種 (1,1)    種 (1,0)
    6          4          9
    2          8          9
    1          9          9
   -2         12          9
   -3         13          9
```

種 `(1, 0)` では五つとも `9 = L²` に潰れる。種 `(1, 1)` では `4, 8, 9, 12, 13` の五つに分かれ、値は `10 − λ` になる。

**`1, 1` から始めたときだけ、番地の側が五つの違う単位を持つ。**

そして単位が違うものは足せない。別の固有値に属する成分を足したものは、どちらの `λ` で測っても `L²` 倍の形を保たない。5組すべてで崩れる。同じ固有値どうしなら足せて、`q₀` が和の起点から決まり直すだけになる。

倍率のほうは違う。起点にも成分にも依らず `L² = 9` の一つだけになる。**長さの単位は起点ごと、倍率は装置で共通**という分かれ方をする。

## 装置の全体像

ここまでを一枚にまとめる。

**入力** ── 120本の有向辺に置いた整数値。何を意味させるかは装置の外で決める。

**担体** ── 正十二面体の20頂点。面の対角線60本で、これは五芒星12個ぶんになる。次数6が一様で、向きを付けると `20 × 6 = 120` 本。

**一歩** ── 隣から入る値を足し、逆向きの値に 3 を掛けて引く。

```
ψ'(u→v) = Σ_{w∼u} ψ(w→u) − 3 · ψ(v→u)
```

係数は `+1` と `−3` だけ。割り算はない。`L = 3`。

**保たれるもの** ── `TᵀT = 9I`。二乗和は一歩ごとにちょうど 9 倍になる。これは120次元すべてに効く。

**動かない部分** ── 81次元。向きが裏返って `−3` 倍になるだけで、場所が動かない。二歩で元の姿に戻る。

**動く部分** ── 39次元。番地ごとの `S` と `O` に降りる。

```
S' = A·K·S − L·O
O' = L·S
S_{n+2} = A·K·S_{n+1} − L²·S_n
```

**目盛り** ── 起点 `(s₀, s₁)` が `q₀ = q(s₀, s₁)` を決め、それがその番地の 1 になる。種 `(1,1)` からは `4, 8, 9, 12, 13` の五つが出る。単位の違うものは足せない。

**読み出し** ── 判別式 `D = λ² − 4L²` の符号で分かれる。`λ = 6` で `D = 0`（退化して開く）、`λ = 2, 1, −2, −3` で `D < 0`（閉じた楕円）。対 `(s_n, s_{n+1})` がその曲線に乗り、曲線が一歩ごとに `L²` 倍に膨らむ。

**器** ── 平衡13進の桁列。上の全部が加算と桁ずらしだけで走る。

これが、整数だけで動く波の装置になる。

---

## ここまで届いたもの

外した三つに、それぞれ別のものが立った。

**複素数** は判別式の符号になった。`D = λ² − 4L²` が負の側で `(s_n, s_{n+1})` の対が回る。状態にも係数にも虚数は要らない。しかも回る半径が `L` に一致する条件と、二乗和が保存する条件が同じものになる。

**極限** は整数の対 `(k, L)` になった。比 `s = kd/2L` を作らずに持つので、割る場面がない。境界は `s = 0` と `s = 1` の二本で、近づく操作ではなく、両側を同じ族として書く。

**割り算** は倍率 `L` になった。次数が一様なら `L = d/2`。五芒星グラフでは `L = 3` で、一歩の係数が `+1` と `−3` の二つだけになる。倍率は全成分に共通なので、同じ歩の中の比較からは消える。

**目盛り** は起点になった。`q₀ = q(s₀, s₁)` がその番地の 1 で、外から入れる必要がない。種 `(1, 1)` からは五つの単位が出て、単位の違うものは足せない。

平衡13進の桁列が、その全部を整数のまま運ぶ。

装置の中身を数えると、120次元のうち81次元は向きが裏返るだけで場所が動かず、39次元が番地の上の二階漸化式として走る。その対は円錐曲線の上に乗り、曲線が一歩ごとに `L²` 倍に膨らむ。19次元は閉じた楕円を回り、番地に一様な1次元だけが開いた形で出ていく。回るものと広がるものが、同じ装置の中で分かれている。

残っているのは二つになった。

**状態の規則** ── 39次元に何を配るか。配る場所は決まったが、配るものと、一歩がそれをどう変えるかの規則がまだない。

**時間** ── 一歩が何の一歩か。角度は `72°` で決まっているが、外の量に結んでいない。長さと倍率が揃ったので、ここは次に測れる。

試みはまだ途中である。ただし、最初に外すと決めた三つは外れ、残っていた目盛りも装置の中から出た。
