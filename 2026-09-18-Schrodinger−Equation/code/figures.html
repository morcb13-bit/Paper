割り算のない波

五芒星グラフの上の一歩。曲線は式から描き、点は実際に走らせた数列から打っています。点が曲線から外れたら、式のほうが誤りです。

図1　伸びるか縮むかを決める放物線

一歩で二乗和がどう動くかは A′ = L²·A + c(k)·Q で決まります。Q ≥ 0 なので、符号を決めているのは c(k) = d·k² − 2L·k だけ。根は k = 0 と k = 2L/d の二つで、内側が縮む側、外側が伸びる側、根の上だけが保存です。

図2　番地の対が乗る円錐曲線

番地に入る辺の和 S は、番地の上で二階の漸化式になります ── sn+2 = λ·sn+1 − L²·sn。隣り合う二項の対には整数の二次形式 q(a,b) = b² − λ·a·b + L²·a² が乗り、一歩ごとに L² 倍になります。判別式は D = λ² − 4L²。
