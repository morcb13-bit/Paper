## 材料は驚くほど少ない

使うのは正五角形1種類だけです。

これを10枚、辺を共有させて輪にすると **円環** ができます。真ん中に正十角形の穴があき、円環の半径は φ² になります（φ = 1.618… 黄金比）。

円環どうしの繋ぎ方は**2種類しかありません**。

| 繋ぎ方 | 中心間の距離 |
|---|---|
| 連続（共有する2枚が隣り合う） | 4.979797 |
| 2つ飛ばし（共有する2枚の間に2枚ある） | 3.077684 |

比はちょうど φ です。以上が材料の全部です。五角形1種、円環、繋ぎ方2種。

座標は最後まで整数で持ちます。ζ = e^{iπ/5} として、点はすべて整数4つ組 (a, b, c, d) で表せます。実数にするのは絵を描く一箇所だけで、途中の判定に浮動小数は一度も使いません。だから「ほぼ一致」がありません。合うか、合わないかだけです。

## 1から13までを鎖にして、積む


**図2：1から13までの整数を図形で表す**

@[codepen](https://codepen.io/editor/morcb13-bit/pen/019fbbe0-fba8-7b1b-a62f-7a8ec24c627e?default-tab=result)

円環を横につないで、長さ n の鎖を作ります。作り方は数の奇偶で決まります。

- **奇数** … 連続の繋ぎだけ。折れ角は全箇所 108° のジグザグ
- **偶数** … 2つ飛ばしを連続で繋ぐ。まっすぐ（180°）

これで 1, 2, 3, …, 13 の単位ができます。どの単位も五角形は 8n+2 枚です。

ここで既に、面白いことが一つ起きています。**偶数の鎖は必ず「2つ飛ばし」を含み、奇数の鎖は一本も含まない。**2で割り切れるかどうかが、数の性質ではなく繋ぎ方の種類として鎖に刻まれています。2の篩が、図形の側に最初から入っている。

1 を一番上に、中央を揃えて、落差が最小になる位置へ順に積みます。

> **計算** … 91環／五角形628枚／重なり0。左端と右端はそれぞれ厳密に一直線（整数の等式で判定）。

積んだ三角形の頂点には、五角形が5枚で囲む穴 ── **五芒星** ができます。

## 立つ場所を変えると、景色が変わる

この図を中心から眺めると、きれいに整っています。五芒星が同心に並び、円環が規則正しく巡っている。

ところが**少し外に出て、別の五芒星の上に立つと、見えるものが変わります。**

五芒星は416個あります。それぞれに立って、そこから見える円環の並びを記録し、回転と鏡映で重なるものを同じとみなして分類しました。

> **計算** … 外周で切れているものを除いた対象で

| 見る半径 | 対象 | 景色の種類 |
|---|---|---|
| 4.5 | 416 | **1** |
| 7 | 356 | 4 |
| 10 | 346 | 4 |
| 15 | 296 | 20 |
| 22 | 236 | **35** |

すぐ足元（半径4.5）では**416個が全部同じ**です。どの五芒星も、まわりを5つの円環に φ³ の距離で囲まれている。ここに例外はありません。

しかし見る範囲を広げるほど、種類が増えていきます。1 → 4 → 20 → 35。

**遠くまで見れば見るほど、同じ景色は減っていく。**この図は910環しかないので半径22で頭打ちになりましたが、先へ行けば二つとして同じものは無くなるはずです。

## それでも、全部が同じ作りをしている

型紙を用意します。五芒星をひとつ置き、そこから最初の数殻ぶんの円環を並べたもの。これを416個の五芒星すべてに、10通りの向き × φ^m 倍で当ててみます。

> **計算** … 型紙が行1〜3（円環6個）のとき

| 倍率 | 当たった五芒星 |
|---|---|
| φ⁰ = 1 倍 | 356個 |
| φ¹ = 1.618 倍 | **0個** |
| φ² = 2.618 倍 | 35個 |
| φ³ = 4.236 倍 | **0個** |

**当たるのは φ² 倍のときだけ。**奇数乗では一度も当たりません。

しかも向きに偏りがあります。当たった35個について型紙の軸が向いている方向を調べると、外向きは**1件も出ませんでした**。全部が図の中心のほうを向いています（180° が最多、範囲は内向き ±54°）。

外側にあとから出てくる列は、最初の型紙を φ² 倍して中心へ向けたもの。**同じ作りが、大きさだけ変えて繰り返されている。**

## ところで、この鎖の長さは何で書けるのか

ここから本題です。

さっき 1 から 13 までの鎖を作りました。あの**長さ**そのものを、図形の言葉で書けないでしょうか。

奇数の鎖はジグザグでした。連続する3環を取ると、108° に開いた **V字** になります。これを敷き詰めてみます。

**図4：奇数の鎖をV字で敷くと、真ん中に過不足が残る**(fig_balanced3.svg)
@[codepen](https://codepen.io/editor/morcb13-bit/pen/019fc6d0-b9b3-7b4e-835c-c851b138ba02?default-tab=result)

起きることは三通りしかありません。

- **ぴったり敷ける** … n = 9, 15, 21 …
- **環が1つ余る** … その1つが余る。n = 7, 13, 19 …
- **1つ足りない** … V字を1枚多く置いて、1環だけ重ねる。n = 5, 11, 17 …

そして**余った環も、重ねた環も、必ず鎖のちょうど真ん中に来ます。**

> **計算** … n = 3 から 29 まで、印の位置が鎖の中心環と毎回一致。被覆は 1..n を過不足なく覆い、3×(V字の個数) + 桁 = n が成立。

つまり桁は **−1, 0, +1** の三つしかない。**平衡3進数**です。

```
 5 = 3×2 − 1     真ん中で1環重ねる
 7 = 3×2 + 1     真ん中に1環余る
 9 = 3×3         ぴったり
11 = 3×4 − 1
13 = 3×4 + 1
```

余りを「2余る」と読まずに「次の3に1足りない」と読み替える。それだけで桁が畳まれます。

面白いのは、**数を数えなくても読めること**です。鎖の真ん中を見る。何も無ければ 0、白い環が1つ立っていれば +1、環が二重になっていれば −1。3で割った余りが、**場所として**そこにあります。

あれだけ複雑だった図形の骨組みが、真ん中の環ひとつの過不足で書けてしまう。

ついでに素数もこれで並びます。3より大きい素数は例外なく「+1 型」か「−1 型」のどちらかで、100以下ならこう分かれます。

- **+1型**（V字が偶数枚） 7, 13, 19, 31, 37, 43, 61, 67, 73, 79, 97
- **−1型**（V字が奇数枚） 5, 11, 17, 23, 29, 41, 47, 53, 59, 71, 83, 89

> **見立て** … ただし逆は言えません。25 も 49 も +1型に入ります。素数だけを選り分ける篩は、この分割則にはまだ現れていない。

## 3は、一段で止まる

平衡3進なら、次の桁も同じように読めるはずです。V字が k 枚あるなら、その k をまた V字で敷けばいい。

やってみると、止まります。

**図4：3つのV字は大きなV字にならない**(fig_ternary_stop.svg)

@[codepen](https://codepen.io/editor/morcb13-bit/pen/019fc6db-fab9-7da9-883d-1734bd7c216b?default-tab=result)

9 = 3+3+3 の三つのV字の中心を結ぶと、折れ角は 108° になりません。

> **計算** … 152.7724°。V字なら 108° のはず。

**三つのV字は、一段上のV字を作らない。**だから同じ読みを繰り返せません。2桁目から先は、紙の上の計算にはなっても、図形の上の操作ではなくなります。

3という比は、この図のどこにも縮小率として現れないのです。

では何が現れるか。**φ です。**型紙が当たるのは φ² 倍のときだけでした。殻の半径を並べても同じことが出ます。

| 種別 | 半径 | φの冪 |
|---|---|---|
| 円環 | 4.236068 | φ³ |
| 円環 | 11.090170 | φ⁵ |
| 五芒星 | 6.854102 | φ⁴ |
| 五芒星 | 17.944272 | φ⁶ |

**円環は奇数乗、五芒星は偶数乗。**交互に現れて、いくらでも続きます。

3は一段で止まり、そこから先を φ が引き取る。

## 外側の記数法

φ の側がどこまで行けるのかを見ます。

この構造の点は、実空間の位置とは別に、もうひとつ値を持っています。**残渣** と呼んでいるものです（整数4つ組を、別の向きで実数に落とした値）。

**図5：左：910環を残渣の色で塗った図　右：同じ点を残渣の平面に置いた図**(b13_window_pair.svg)(図1と同じ図）

@[codepen](https://codepen.io/editor/morcb13-bit/pen/019fc6be-f671-7748-b1b1-595c084eedff?default-tab=result)

> **計算** … 910環の図は実空間で半径 88.84 まで広がるが、残渣は半径 1.2557 の中に全部収まる。φ² 倍の拡大は実空間を 2.618034 倍に伸ばし、残渣を 0.381966 倍（= 1/φ²）に縮める。積は変わらない。

実空間は無限に伸ばせますが、残渣は外に出られません。この有界な領域を **窓** と呼びます。

景色を決めているのは位置ではなく残渣のほうです。残渣が近い点どうしは、実空間でどれだけ離れていても同じ景色になる。逆に実空間で少しずらすと残渣が大きく飛ぶので、景色は別物になる。だから同じ景色の点は、実空間で寄り集まらず**まだらに散ります**。

伸ばした分だけ、必ず窓の中へ折り返される。**外へ無限に広がっても、残渣は窓から出ない。**だから景色の種類は有限の語彙で書けて、それでいて同じ景色が二度と揃わない。

## 二つの記数法

まとめると、同じ図の中に記数法が二つ入っています。

| | 内側（鎖の長さ） | 外側（相似と間隔） |
|---|---|---|
| 底 | 3 | φ |
| 桁 | −1, 0, +1 | φ の冪 |
| 現れ方 | 真ん中の環の過不足 | 型紙が当たる倍率、殻の半径 |
| 続くか | 一段で止まる | いくらでも続く |

そして**どちらも掛け算を使っていません。**

φ² = φ + 1 なので、φ 進の繰り上がりは「011 → 100」という足し算の置換規則だけで済みます。3の側も、1足りないか1余るかを見ているだけです。底が違っても、やっていることは同じです。

複雑さと単純さが同居しているのではありません。**同じ足し算が、内側では3の桁として、外側では φ の桁として現れている。**それだけのことが、二つとない景色を作っています。

> **見立て** … これは宇宙の構造そのものではないか。

そこは測っていません。測ったのは、上に並べた数字だけです。

*Nature knows only addition.*

## 再現

図と検査スクリプトは以下で再現できます。すべて標準ライブラリのみ、外部データ不要です。

- `b13_chain_units.py` … 1〜13の鎖を作り、積んで三角形にする（検定7項目）
- `draw_star10.py` … 五芒星を中心に10枚を組む（検定4項目）
- `star_views.py` … 五芒星ごとの景色を分類する（検定4項目）
- `similar_probe.py` … 型紙を当てて相似形を探す（検定3項目）
- `chain_balanced.py` … 鎖の長さを平衡3進で読む（検定7項目）
- `draw_window_pair.py` … 実空間と残渣を並べて描く（検定3項目）

各スクリプトの冒頭には、**測る前に書いた**検査項目（何が OK で何が NG か）を置いてあります。全項目が OK で終わる検査は、反証できない検査を書いた可能性が高いので、わざと落ちる条件も併記しました。

- 積む順を逆にすると、7項目のうち4項目が NG に変わります
- `chain_balanced.py` の検定7（V字三つが一段上のV字になるか）は、**落ちるのが正しい**検査です。3進が一段で止まることの確認になっています
- V字の位置を探すとき鏡映を許さないと、奇数位置しか見つからず、平衡3進が立たなくなります。V字自体が鏡対称なので、許すのが正しい読みです
