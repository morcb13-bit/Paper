## 1. 前稿の発火則は、窓の判定そのものだった

前稿の発火則を書き換える。

```
{nφ} + 1/φ > 1
⟺ {nφ} > 1 − 1/φ = 1/φ²
⟺ {nφ} ∈ (1/φ², 1)      ← 長さ 1/φ の区間
```

これは切断投影法の受理条件の形をしている。内部空間が円周、窓が区間、点 n が受理されるのは σ(n) が窓に入るときである。

**確定した観測：** n = 1〜20000 で、発火則と窓判定の不一致は0件。発火位置とフィボナッチ語の a の位置は完全一致（語長987、a が610個、発火610個）。受理集合の間隔は2種類しかなく、個数は F₁₄ = 377 と F₁₃ = 233 である。

前稿の装置は1次元の準結晶だった。であれば、次元を上げられる。

```
前稿   内部空間 [0,1)   窓 = 長さ1/φ の区間   縁 2個   文字 2種
本稿   内部空間 C       窓 = 正十角形         縁 10個  文字 6種
```

窓の縁が2個から10個に増えるだけで、判定の形は変わらない。構成要素を並べると対応が見える。

| 役割 | 1次元装置 | 2次元装置 |
|---|---|---|
| 生成側 | 整数点 n | 円分整数格子点 p |
| 内部写像 | {nφ} | σ(p) ∈ C |
| 窓 | 長さ 1/φ の区間 | 正十角形 |
| 境界 | 2点 | 10辺 |
| 発火 | 区間への出入り | 辺の横断 |
| 残渣の姿 | 2種類の間隔 | ひし形・反転斑 |
| 黄金署名 | 間隔比と個数 | 間隔の φ 冪と方向 |

## 3. 判定に浮動小数を使わない

正十角形の各辺は有限個の一次不等式で書ける。

```
⟨n_j, σ(p) − γ⟩ ≤ h,    j = 0, …, 9
```

窓を方向 u に γ(t) = γ₀ + t·u と動かすと、点 p が辺 j を跨ぐ時刻は解析的に出る。

```
t_{p,j} = ( ⟨n_j, σ(p) − γ₀⟩ − h ) / ⟨n_j, u⟩
```

走査は要らない。全反転時刻を直接列挙してソートし、差分を取る。

さらに重要なのは、これが**有理数体を出ない**ことである。σ(p) ∈ Q(ζ₁₀) のとき

```
Re( w · conj(ζ^j) ) = ( w·conj(ζ^j) + conj(w)·ζ^j ) / 2
```

は実部分体 Q(φ) に落ちる。したがって窓の判定も反転時刻も、`p + qφ` の形のまま扱える。大小比較は

```
2(p + qφ) = (2p + q) + q√5
```

の符号を、(2p+q)² と 5q² の整数比較で決めればよい。

```python
class Qp:
    """p + q·φ,  φ² = φ + 1。判定に浮動小数を使わない。"""
    def __init__(self, p=0, q=0):
        self.p = Fraction(p); self.q = Fraction(q)

    def __mul__(s, o):
        return Qp(s.p*o.p + s.q*o.q,
                  s.p*o.q + s.q*o.p + s.q*o.q)

    def inv(s):
        N = s.p*s.p + s.p*s.q - s.q*s.q      # ノルム
        return Qp((s.p + s.q)/N, -s.q/N)

    def sign(s):
        A = 2*s.p + s.q; B = s.q
        if A == 0 and B == 0: return 0
        if A >= 0 and B >= 0: return 1
        if A <= 0 and B <= 0: return -1
        return (1 if A*A > 5*B*B else -1) if A > 0 else (-1 if A*A > 5*B*B else 1)
```

## 4. 主結果 ── 間隔は 1/φ の冪しか現れない

ρ = 1/φ と書く。窓を方向0°に動かしたときの反転間隔は、次の6種類だけだった。

```
ρ⁹/2   0.0065778   12回
ρ⁸/2   0.0106431   18回
ρ⁷/2   0.0172209   18回
ρ⁸     0.0212862    7回
ρ⁶/2   0.0278640    6回
ρ⁷     0.0344419    3回
```

**確定した観測：** 加法関係6件が Z[φ] 上で厳密に一致する。

```
ρ⁹/2 + ρ⁸/2 = ρ⁷/2
ρ⁹/2 + ρ⁸   = ρ⁶/2
ρ⁹/2 + ρ⁶/2 = ρ⁷
ρ⁸/2 + ρ⁸/2 = ρ⁸
ρ⁸/2 + ρ⁷/2 = ρ⁶/2
ρ⁷/2 + ρ⁷/2 = ρ⁷
```

比も `(0 + 1φ)` すなわち φ に厳密一致する。「φらしい小数が出た」ではなく、代数的な等式である。

**確定した観測（M = 1〜5、h = 1, φ, 2, φ² の範囲）：** 格子の打ち切り M を1つ上げると、現れる冪の窓が1段ずつ動く。

| M | 現れる冪 |
|---|---|
| 1 | ρ⁴ 〜 ρ⁷ |
| 2 | ρ⁵ 〜 ρ⁸ |
| 3, 4 | ρ⁶ 〜 ρ⁹ |
| 5 | ρ⁷ 〜 ρ¹⁰ |

集合の形は変わらず、n が平行移動するだけである。一方、**窓の大きさ h を 1, φ, 2, φ² と振っても冪集合は完全に同一**だった。**今回調べた範囲では、現れる冪集合は窓サイズ h に依存せず、格子打ち切り M とともに移動した。** 窓を極端に小さくした場合や、格子範囲との相対関係を変えた場合までは調べていない。

方向36°だけは4種類に退化する（ρ の整数冪が消える）。0°と72°は6種類。これは D₅ 対称と整合する。

## 5. フィボナッチは間隔の個数と座標に住む

なぜ前稿までフィボナッチが見えなかったか。**増幅率を測っていたから**である。

黄金回転は零エントロピー系なので、リャプノフ指数は0になるのが正しい。0という正しい署名に、失敗という誤った名札を付けていた。

フィボナッチは別の場所にいる。

**確定した観測（1次元、対照実験）：** 黄金回転 {n/φ} をフィボナッチ数 N = F_k で切ると、二つの主要間隔の個数が F_{k−2}, F_{k−1} になる。

| N | 間隔の個数 |
|---|---|
| 34 | 13, 21 |
| 55 | 21, 34 |
| 89 | 34, 55 |
| 144 | 55, 89 |
| 233 | 89, 144 |

**既知の数学：** 三距離定理。{nα} の間隔は高々3種類で、最大＝他の2つの和。α = 1/φ のとき比は 1 : φ : φ²。

**確定した観測（2次元）：** 間隔の Z[φ] 座標そのものが連続するフィボナッチ数の対である。

```
ρ⁷ = −21 + 13φ      (F₈, F₇)
ρ⁸ =  34 − 21φ      (F₉, F₈)
ρ⁹ = −55 + 34φ      (F₁₀, F₉)
```

**既知の数学：** ρ^n = (−1)ⁿ(F_{n+1} − F_n φ)。φ^n = F_n φ + F_{n−1} の裏返しである。

> フィボナッチは間隔の個数に、φ は間隔の比に住んでいる。どちらも増幅率には現れない。

## 6. ひし形は残渣そのものだった

五角形の外接半径を1とする。五角形の一辺 s は s² = 3 − φ。

細ひし形の短対角 d は、Z[φ] 上で

```
d²   = 7 − 4φ
ρ²s² = (2 − φ)(3 − φ) = 7 − 4φ      ← 厳密一致
```

つまり **d / s = ρ = 1/φ**。ひし形の細い方の寸法は、辺に残渣作用素を一回かけたものである。

角度でも同じことが起きている。

```
正五角形3枚 = 3 × 108° = 324°
360° − 324° = 36°          ← ひし形の鋭角にちょうど一致
```

**B13の読み：** ひし形は、五角形を詰めたときに出る余りを実体にしたものである。計量では ρ を一回かけた残り、角度では 36° の欠損。どちらも残渣であり、平面ではそれが消えずに図形として残る。

![ひし形は残渣　fig2_rhombus_residue.svg](https://static.zenn.studio/user-upload/4a9b3484da6f-20260727.png)


球面なら 36° は曲率として消費されて見えなくなる。正十二面体は頂点20個 × 36° = 720° でちょうど閉じる。平面は全曲率0なので消費できず、ひし形として置くしかない。

> **見えなかったものが見えるようになったのは、閉じない場所に置いたからである。**

おまけに一つ、きれいな数が出た。細ひし形の長対角は

```
D² = 5      ちょうど。φ を含まない有理整数
```

D = √5。体の判別式そのものが対角線に立っている。

ひし形の三段も φ の冪で閉じる。中/小 = φ²、大/中 = φ、大/小 = φ³。面積は φ⁴、φ²、φ⁶。

## 7. 積み上げは Z[φ] の中でフィボナッチになる

円環の層は、5回回転対称で各辺に1個ずつ増える整数加算である。数える列は 5, 10, 15, … の等差でしかない。

ところが**積み上がる場所は Z[φ] の中**なので、そこではフィボナッチ回帰が支配する。

```
φ² = 1 + 1φ      φ⁶ =  5 +  8φ
φ³ = 1 + 2φ      φ⁷ =  8 + 13φ
φ⁴ = 2 + 3φ      φ⁸ = 13 + 21φ
φ⁵ = 3 + 5φ      φ⁹ = 21 + 34φ
```

**確定した観測：** 回帰が厳密に成立する。φ² + φ³ = φ⁴、φ³ + φ⁴ = φ⁵、φ⁴ + φ⁵ = φ⁶、φ⁵ + φ⁶ = φ⁷。

そして確定半径が実際にそう積み上がっている。

```
6.8541 + 8.9721 = 15.8262
（五芒星2 ＋ 小ひし形中心a ＝ 小ひし形中心b）
```

五芒星の半径は φ の冪ちょうどである。五芒星2 が φ⁴（r² = φ⁸ = 13 + 21φ）、五芒星3 が φ⁶（r² = φ¹² = 89 + 144φ）。どちらも係数が連続フィボナッチ対。

各層が φⁿ だけ伸びるとして累計すると、累計の Z[φ] 係数は (F_n − 1, F_{n+1} − 1) になる。n = 1〜8 で 8/8 一致した。

> 加算は整数、積み上げは黄金。

## 8. 第n層のコード

前稿までのコードは確定55環の固定表で止まっていた。層番号を持たせて一般化する。

### 8.1 層と起源を持たせる

```python
class LayeredFigure(Figure):
    def __init__(self):
        super().__init__()
        self.ring_level:  dict[Zeta, int] = {}
        self.ring_origin: dict[Zeta, set[str]] = {}

    def pentagram_candidates(self) -> set[Zeta]:
        """五芒星規則が要求する円環中心"""
        out = set()
        for g, k2 in self.pentagrams():
            for i in range(5):
                c = zadd(g, zrot(PHI3, k2 + 2*i))
                if c not in self.ring_set:
                    out.add(c)
        return out

    def rhombus_candidates(self) -> set[Zeta]:
        """大ひし形の欠けた頂点"""
        out = set()
        for a, b in self.skip_pairs():
            for v in CONT_VECS:
                c = zadd(a, v)
                if c not in self.ring_set and is_cont(c, b):
                    out.add(c)
        return out

    def grow_one_layer(self, level: int) -> dict[str, set[Zeta]]:
        P = self.pentagram_candidates()
        R = self.rhombus_candidates()
        added_p, added_r = set(), set()
        for c in sorted(P | R):                    # 整数座標順＝順序非依存
            if self.add_ring(c):
                if c in P: self._tag(c, level, "pentagram"); added_p.add(c)
                if c in R: self._tag(c, level, "rhombus");   added_r.add(c)
        return {"pentagram_only": added_p - added_r,
                "rhombus_only":   added_r - added_p,
                "both":           added_p & added_r,
                "all":            added_p | added_r}
```

起源を残すのは設計選択である。両規則が同じ中心を要求する場所は、二つのパターンが合流した点であり、重複として消すより観察対象として残す価値がある。

### 8.2 生成世代と殻は別物

同じ円環でも、規則の適用順によって一手早く現れることがある。完成配置だけで一意に決まる番号が欲しければ、円環中心グラフの幅優先探索を使う。

```python
def shell_levels(self, seeds):
    lev = {c: 0 for c in seeds if c in self.ring_set}
    q = deque(lev)
    while q:
        a = q.popleft()
        for b in self.rings:
            if b in lev: continue
            if is_cont(a, b) or is_skip(a, b):
                lev[b] = lev[a] + 1; q.append(b)
    return lev
```

**確定した観測：** 60環において、生成世代と殻番号が一致しない円環は 55/60。殻ごとの円環数は {0:5, 1:10, 2:10, 3:20, 4:15}。

**B13の読み：** この差そのものが残渣である。同じ殻にいながら、五芒星から発火したものと、ひし形の欠損補完から発火したものでは、履歴が違う。

### 8.5 インフレーションで継ぐ

飽和した先は、外へ足すのではなく φ³ の相似で継ぐ。Z[ζ₁₀] では φ³ も整数4成分なので、誤差なしで書ける。

PHI3 = (3, 0, 2, -2)          # φ³

def inflate(rings, n=1):

    s = zpow(PHI3, n)

## 9. 誤り台帳（47〜50）

- **47 測定量の誤り。** フィボナッチ構造を増幅率（リャプノフ指数）に探した。黄金回転では指数が0なのが正しく、構造は間隔の種類・比・個数に現れる。
- **48 窓形状の誤り。** 正十角形と記述しながら円板で実装した。円板は境界方向の10回対称性を失わせ、反転間隔を走査刻みの整数倍へ退化させた。
- **49 層の見落とし。** 層の個数列が等差であることだけを見て「フィボナッチではない」と結論した。数える列と積み上がる場所は別で、積み上げは Z[φ] の中でフィボナッチ回帰になる。
- **50 層の取り違え。** 担体の間隔を測って「射影の産物は原理的に出ない」と書いた。前稿は素数と幸運数が射影を通じた回収であることを明示している。担体と射影を混同した。

共通の型は一つである。

> **対象の構造が持つ言葉を、測定の前に捨てた。**

判別法として使えるのは、測定の前に**自分が導入した定数を止めたら結果が消えるか**を確認することである。κ を1にすればリャプノフ指数は消える。最初に見ていれば一度で済んだ。

どれも Z[φ] 係数は連続するフィボナッチ対である。そして中央にひし形がある。

> **ひし形は二つの塔の間にある。内部空間で縮んでいた残渣が、実空間へ出た瞬間の姿である。**

前稿が残渣を数として読む稿なら、本稿は残渣を幾何として読む稿である。到達点は「ペンローズには黄金比が現れる」ではなく、**黄金比の逆作用が、ひし形の寸法として実体化する**ところまで来ている。

前稿の装置と本稿のペンローズは、内部空間の次元と窓の縁の数が違うだけの同じ機械である。前稿の連接の選択肢（前後2択）が、2次元では方向の選択（10方向）になる。方向36°だけが退化することも測定で出ており、前稿の「自己相似は同方向を続けた一経路の帰結」に対応する位置にある。

Nature knows only addition. 平面は閉じないので、余りが図形として残る。
