## 結論

正五角形10枚で作った円環を、**連続接続と2つ飛ばし接続の2種だけ**を使い、**5回回転対称と等半径条件を保ちながら**並べていく。この規則から、

- **五角形とひし形でできたタイリング**（円環そのものが作る図）
- **正五角形とひし形でできたタイリング**（円環の中心を結んだ図）

の2枚が同時に立ち上がる。この2枚は φ³ のスケール違いで**厳密に一致する**。

そして、片方の図が行き止まったとき、もう片方の図が次の一手を教えてくれる。

判定はすべて整数で行っている。実数は描画の1箇所しか使っていない。

## 1. 円環を2つ並べる方法は2通りしかない

![](https://static.zenn.studio/user-upload/48f7588e2808-20260726.png)

外接半径1の正五角形を10枚、中心のまわりに並べる。隣どうしは辺を共有し、中心には正十角形の穴が残る。これを**円環**と呼ぶ。円環の半径は φ²、五角形の中心間の距離は φ になる。

円環を2つ並べる方法は2通りしかない。

| 呼び名 | 中心間距離 | 共有する五角形 |
|---|---|---|
| **連続** | φ²·\|ζ⁴−1\| ≒ 4.9798 | 隣り合う2枚 |
| **2つ飛ばし** | φ²·\|ζ²−1\| ≒ 3.0777 | 間に2枚を挟んだ2枚 |

比は厳密に φ。この2種だけを使って、5回回転対称を保ったまま広げていく。それがこの図の全部である。

:::message
**用語について**：この記事は円環・番地・連続・2つ飛ばし・五芒星という、この構成自身の言葉で書く。既存の数学（ペンローズ充填、インフレーション）に対応づける話は9章にまとめて置いた。

## 2. 番地と向き

五角形の向きは、円環の中心から見た方角だけで決まる。中心から k 番目の方角にある五角形を**番地 k** と呼ぶと、向きは k の偶奇のみで決まり、それ以外の自由度はない。

円環は36°回転で自分自身に重なるので、円環に回転の自由度はない。**円環の位置は中心座標だけで決まる**。

番地は b13phase の位相整数にそのまま乗る。

```
BASE = 3120 = 60 × 52
36° = 312 = 6 × STEP_MIN
番地 k → 位相 k × 312
```

## 3. 成長規則と、その飽和

![](https://static.zenn.studio/user-upload/b9ecd9e26bba-20260726.png)

図の中には**五芒星**（五角形5枚に囲まれた星形の空隙）が現れる。ここに強い規則がある。

> 五芒星の周りには、第一層とまったく同じ形の円環が5個できる。

整数の等式で書ける。五芒星の中心を g とすると

```
囲む五角形    g + φ  · ζ^(k+2i)     （番地の偶奇は (k+1) mod 2）
囲む円環中心  g + φ³ · ζ^(k+2i)     （i = 0..4）
```

第一層はこの規則の g = 0 の場合そのものである。

この規則を回すと円環は 25 → 45 → 55 と増え、五芒星は 6 → 16 → 21 と増える。**この生成規則では、そこで停止する**。

停止する理由ははっきりしている。55環の時点で、21個の五芒星は**すべて5円環に囲まれ切っている**。規則が要求する新しい円環は0個。計算が難しいのではなく、規則にやることが残っていない。

## 4. 円環の中心を結ぶ

円環を並べていたつもりが、中心だけを見ると別のタイリングが現れる。

**円環の中心だけを取り出して線で結ぶ**。

現れるのは、正五角形とひし形だけでできた別のタイリングだった。

- 正五角形：外接半径 φ³、辺はすべて連続接続
- ひし形：辺 φ³·\|ζ²−1\|、短対角が2つ飛ばし接続

しかも**正五角形の重心は、もとの図の五芒星の位置に厳密に一致する**。星があった場所に、大きな五角形が来る。

:::message
2つ飛ばし接続は、このひし形の**短対角**にあたる。中心図形の面を取るときに2つ飛ばしを辺として描くと、ひし形が三角形2枚に割れてしまう。連続接続だけで面を取ること。
:::

## 5. ひし形が中心を向く

![60環と完成した大ひし形 pentagon_60rings.png](https://static.zenn.studio/user-upload/84ef5f9b8181-20260726.png)

この構成には、もう一つ条件がある。

> 各層は2つ飛ばしの接続則で重ならない。こうするとひし形はすべて中心座標の方を向く。

ひし形の重心は2つの円環の中点にあり、長軸は接続ベクトルに常に垂直になる。したがって

```
長軸が中心を向く ⟺ (C₂−C₁) ⊥ (C₁+C₂) ⟺ |C₁| = |C₂|
```

**2つ飛ばしで結ばれる2環は必ず等半径**。これが層の定義そのものになっている。

この条件は見た目の問題ではない。外した図を作って比べると、

| | 中心図形の面 |
|---|---|
| 条件を守った図 | 正五角形21 + ひし形10 で閉じる |
| 条件を破った図 | ひし形15 / 正五角形41 / **15角形5** / 不正な五角形5 |

破ると中心図形が壊れる。ペンローズには存在しない15角形が出る。

そしてこの条件は**鏡映対称より強い**。条件を破った図も鏡映では閉じていた。対称なだけでは足りない。

## 6. 行き止まりを越える

55環で成長規則は尽きた。ここで中心図形の側を見る。

大ひし形は**5個しか完成していなかった**。半径15.8262の2つ飛ばし対5組は、ひし形の頂点が1個ずつ欠けている。

**その欠けた頂点が、次の円環中心である。**

整数の等式で一意に決まる。

```
C_new = a + φ²(ζ⁴−1)·ζ^k     （b からも連続接続になる k を選ぶ）
→ 半径 20.5623 の5点
```

**この点は一意に決まる。** a と b の両方に連続接続する点は、Z[ζ₁₀] 上に常に
ちょうど2個ある（ひし形の2頂点）。完成済みの5組では2個とも既に図の中にあり、
未完成の5組では1個が既にあるので、欠けは1個に定まる。その点は番地の偶奇条件と
重なりゼロ条件も満たす。選択の余地はない。

| | 55環 | → | 60環 |
|---|---|---|---|
| 円環 | 55 | | 60 |
| 五角形 | 385 | | 420 |
| 大ひし形 | 5個（未完成5組） | | **10個すべて完成** |
| 重なり | 0 | | 0 |
| 番地の偶奇食い違い | 0 | | 0 |
| 2つ飛ばしの異半径 | 0 | | 0 |


**2つの規則が交互に働いている。** 五芒星の周りに円環を置く規則が尽きたら、大ひし形の欠けを埋める規則が次を出す。片方が止まったところで、もう片方が動く。

## 8. 整数だけで書く

座標に実数を使うと、重なり判定に閾値が要る。閾値は図が大きくなるほど効かなくなる。だから最初から整数で書く。

**座標** は Z[ζ₁₀] の整数4成分。ζ = e^{iπ/5} として

```python
Zeta = tuple[int, int, int, int]     # a + bζ + cζ² + dζ³
PHI  = (1, 0, 1, -1)                 # φ。φ² − φ − 1 = 0 が厳密に成立
```

ζ⁴ = −1 + ζ − ζ² + ζ³ で畳む。掛け算は整数の畳み込みだけ。

**距離** は二乗長を Z[φ] の整数対 (p, q) = p + qφ で持つ。距離が等しいかどうかは**タプルの一致**で判定できる。近似は入らない。

```python
def norm2(a: Zeta) -> tuple[int, int]:
    z = zmul(a, zconj(a))
    assert z[1] == 0 and z[3] == -z[2]      # 実数であることが構造的に出る
    return (z[0] - z[2], z[2])
```

この `assert` は検算ではなく、構造の確認である。共役を掛けると虚部が構造的に消えるので、
二乗長は必ず実部分体 Z[φ] に落ちる。落ちた先の基底が 1 と φ なので、
`z[1] == 0 and z[3] == -z[2]` が成り立ち、係数 (p, q) がそのまま取り出せる。

**大小比較** も整数で閉じる。2(p+qφ) = (2p+q) + q√5 なので、符号は (2p+q)² と 5q² の比較で決まる。

```python
def phi_sign(x):
    A, B = 2*x[0] + x[1], x[1]
    if A == 0 and B == 0: return 0
    if A >= 0 and B >= 0: return 1
    if A <= 0 and B <= 0: return -1
    return (1 if A*A > 5*B*B else -1) if A > 0 else (-1 if A*A > 5*B*B else 1)
```

**向き** は b13phase の BASE=3120 位相整数。番地 k → k × 312。

実数を使うのは、面の巡回順を決めるところと描画だけ。判定には一切使わない。

:::message
b13phase の `constants.py` には、φ の閉包が要る計算では BASE 単位の丸め整数を使わず Z[ζ₁₀] を使うこと、と明記されている。この記事の実装はその指示に従っている。位相（向き）は b13phase、座標は Z[ζ₁₀] という分担になる。
:::

検証の出力：

```
構成: {'円環': 60, '五角形': 420, '五芒星': 21}

  重なり0: True
  偶奇食い違い0: True
  2つ飛ばし対: 10
  全て等半径: True
  中心図形の面: {'正五角形': 21, 'ひし形': 10}
  正五角形の重心 = 五芒星: True
  ひし形の中心 = 細ひし形の中心: True
  ひし形の辺の二乗長: (7, 11)
  φ⁶ × 小ひし形の辺: True
```

`(7, 11)` は 7 + 11φ。これが小さいひし形の辺の φ⁶ 倍と、整数の等式で一致する。

## 9. B13phase(base3120)との接続

**構造角はすべて 156 BASE単位の格子に乗ります。**

接続10方向・円環→五角形10方向・五芒星→円環5方向、すべての方位を BASE単位で出すと `{0, 156, 312, 468, …, 2964}` の20個。その最大公約数がちょうど **156**。そして `3120 ÷ 156 = 20`、割り切れます。

角度の量子が全部13の倍数でした。

| | BASE単位 | |
|---|---|---|
| 6°（STEP_MIN） | 52 | = 4 × 13 |
| 18°（接続方向の刻み） | 156 | = **12 × 13** |
| 36°（番地1つ） | 312 | = 24 × 13 |
| 72°（5回対称） | 624 | = 48 × 13 |
| 360° | 3120 | = 240 × 13 |

ペンローズ側の角度格子は20分割（18°刻み）で、それが 3120 を 156 で割り切る。余因子が 12·13 です。

**そして、今回導出した新層がちょうどそこに乗っていました。**

絶対方位が BASE整数になる円環は 60点中20点だけです。半径² で言うと `(5,8)=φ⁶`、`(34,55)=φ¹⁰`、`(52,84)`、そして **`(117,189)`** ── 最後のが、大ひし形の欠けを埋めて出した半径 20.5623 の5点です。方位が 312 の倍数、つまり36°の倍数ちょうど。b13phase の格子に乗る側に入っています。

## 10. 何が当たり前で、何がそうでないか

正直に線を引いておく。

**当たり前の側**：スケール違いで2枚が重なること自体は、ペンローズ充填の自己相似（インフレーション）そのものである。星の位置に上位の五角形が来る対応も、既知の合成規則にあたる。数学的に珍しい現象ではない。

**「無限に続けるために必要」の正確な形**：ひし形が中心を向く条件は、敷き詰めが続くために必要なのではない。条件を破った図でも五角形の重なりは0だった。必要なのは**自己相似を保って続く**ためである。中心図形がタイリングのまま次の層を与え続ける、その性質を守っている。実際、60環の次の層はこの条件からしか出ていない。

**自明でない側**：「五角形10枚の円環」という単位は、ペンローズ理論から定義したものではない。手で描いて見つけた単位である。その円環の中心という導出された点が、上位タイリングの頂点に**厳密に**乗った。ここは確かめるまで分からなかった。
