## 1. 逆をやる

本体では、網膜の中心を信号に合わせました。中心を振動の中心に置き、傾きを進行方向に合わせ、ズームで振幅に合わせる。三つのつまみを全部「合わせる」側に使う話です。

ここでは逆をやります。**わざと中心をずらす。**

ずらすと何が起きるか。答えは一語で出ます ── **窓になります。**

## 2. 機構

この装置で場所が在るかどうかは、残渣が窓の中にあるかどうかで決まります。

```
場所 v が在る            ⟺  σ(v) が窓 W の中
d だけずらした側に在る   ⟺  σ(v) − σ(d) が W の中
```

両方が同時に成立するのは、次のときだけです。

```
σ(v) ∈ W ∩ ( W + σ(d) )
```

右辺は窓の形をしています。**ずらしたぶんだけ窓が細くなる。** ずらし量そのものが新しい窓を決めている、というのがこの増補の全部です。

## 3. 測ったこと

担体は 60環（五角形420枚・五芒星21個）。道具から生成し、重なり0・2つ飛ばし対が全て等半径であることを通してから使っています。判定はすべて Q(φ) の符号判定で、浮動小数は表示のときだけです。

| 検定 | 中身 | 判定 |
|---|---|---|
| SW1 | 担体を直に突き合わせた一致集合と、窓の判定だけで作った集合が一致するか | **OK**（16本すべて。食い違い0） |
| SW4 | 窓の外郭は五角形か | **OK**（5頂点） |
| SW8 | ずらした窓に新しい辺の向きが出るか | **OK**（168本中0件） |
| SW5 | 閉じる条件は W+(−W) で書けるか | **OK**（十角形・例外0） |
| SW9 | 窓が開く実長の下限 √N ÷ R₁₀ を担体の一歩が上回るか | **OK**（8種すべて） |
| SW6 | 窓の広さは残渣の長さだけで決まるか | OK（60環の範囲では等方） |
| SW7 | 面積比が一致の割合を予言するか | **NG**（差の最大 0.1119） |

反証の用意として、格子に乗らないずらし（実長 1.0000 と 0.6180）を4本入れてあります。いずれも一致0。検定SW1 は NG を返せます。

SW7 が NG なのは担体が有限だからです。長くずらすほど、ずらした先が図の外へ出ていく。窓の効果と画角の効果が同じ数字の中で混ざっています。**この一件は1245環で測り直すまで未決です。**

## 4. 出てきた形（三つ）

### 4-1. ずらしても窓の向きは変わらない

窓は五つの辺を持ちます。ずらした窓も同じ五つの辺の向きしか持ちません。168本のずらしを試して、新しい向きは一件も出ませんでした。

起きているのはこれだけです ── **ずらした側に背を向けた辺だけが内側へ寄る。** 辺の数は 3・4・5 のいずれかで、5を超えることがない。窓は細くなりますが、傾くことも回ることもありません。

### 4-2. 閉じる条件は十角形

ずらしを大きくしていくと、どこかで窓が閉じます。その境界がきれいに出ました。

```
窓が開く  ⟺  ずらしの残渣 σ(d) が W+(−W) の中
```

窓が正五角形なので、W+(−W) は**正十角形**になります。135本で例外ゼロ。この十角形の差し渡しは、窓の対角線と同じ長さです。

円環の中心に開いている穴も正十角形でした。同じ十角形が、今度は「窓が開くかどうか」の判定図形として出てきます（見立て。二つが同じものだという証拠はまだありません）。

### 4-3. 絞りの向きが逆

この装置には既知の一行があります。

```
実空間の長さ × 残渣の長さ = √N
```

これをずらしに当てると、次のようになります。

```
ずらしを短くする  →  残渣が大きくなる  →  窓が細くなる
ずらしを長くする  →  残渣が小さくなる  →  窓が広くなる
```

**実空間の直感と逆です。** 少しだけずらしたつもりが、いちばん窓を絞る操作になっている。

実測（窓 0.354102 のとき）：

| ずらし | 実長 | 残渣 | 新しい窓の面積比 |
|---|---|---|---|
| 2つ飛ばしの一歩 | 3.077684 | 0.726543 | 0.0235 |
| 連続の一歩 | 4.979797 | 0.449028 | 0.2999 |
| クラスタ間の一歩 | 8.057480 | 0.277515 | 0.5483 |
| 一段上（φ²） | 21.094759 | 0.106021 | 0.8202 |

そして窓が完全に閉じる境界も、同じ一行から出ます。

```
窓が開く実長の下限 = √N ÷ （十角形の外接半径）
```

ノルム5の一歩なら 2.6858、ノルム25なら 6.0057、ノルム55なら 8.9079。担体の中の一歩はすべてこの上にありました（8種で例外0）。**実長がこれを下回るずらしは、どんなに図を大きくしても対応する場所を持ちません。**

## 5. 第四のつまみ

本体では三つのつまみを立てました ── 中心・傾き・ズーム。ここに四つ目が加わります。

**ずらし＝絞り。** ずらし量を選ぶと窓の広さが決まり、窓の広さが「どれだけの場所が生き残るか」を決めます。しかも生き残った場所の並びは、また同じ格子と新しい窓で書けるので、**間引いた後も準周期のまま**です。粗くしても構造が壊れない。

ズームとの違いははっきりしています。

- **ズーム**（段）は φ² 刻みで、実空間と残渣を同時に伸縮させます。積は不変
- **ずらし**（絞り）は実空間の大きさを変えずに、残渣の側だけを切ります

方眼のセンサーで画素を間引くと、間引いた分だけ模様が崩れます。この装置では窓が細くなるだけで、五つの辺の向きは最初のまま残ります。

## 6. 弱いところ

正直に三つ書いておきます。

1. **窓の値が決まっていません。** 上の表の 0.437694・0.832544・面積比はすべて窓 0.354102 を使った数字です。窓が変われば全部動きます。窓に依らないのは、ずらしが窓を作るという形そのもの（SW1）、辺の向きが増えないこと（SW8）、閉じる条件が W+(−W) であること（SW5）、下限が √N÷R₁₀ の形をしていること（SW9）の四つだけです
2. **SW7 が NG です。** 面積比は一致の割合を追いますが、厳密には合いません。担体が有限で画角が混ざっているのが原因という読みですが、確かめていません
3. **1245環で再現していません。** SW6（等方に見えた件）と SW7 は、担体を広げないと判定が弱いままです
