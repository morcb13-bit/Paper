# ペンローズタイリングの可能性 ── 2026-08-10 覚え書き

帳簿は二つある。**通ったもの**と**通らなかったもの**を分けて書く。
公開物には通ったものだけを載せるが、この文書は記録の側なので両方を持つ。

## 1. 目を動かす装置として（いま最も強い）

**確定。**中心・向き・段のすべてが整数で閉じ、何手合成しても丸めが積まれない。

| 操作 | 五角形の網膜 | 四角格子 |
|---|---|---|
| 中心を移す | 整数加算4回 | 画素単位なら丸め0（**差なし**） |
| 36°回す | `(a,b,c,d)→(−d, a+d, b−d, c+d)` 加減4回・乗算0 | 90°の倍数だけ丸め0。36°は最大 0.9776px ずれ、10回転で 0.2853px 残る |
| 段を上げる | (1,φ) 基底で `[[1,1],[1,2]]` 加算3回・乗算0 | 2倍なら丸め0、φ²倍は不可 |
| 1000手の合成 | **丸め0**（段0〜3・移し200手なら番地は11ビット） | 段を固定しても 500手で 20.9px（セル10個ぶん）漂う |

- 段数は画素数の対数。1920×1080 で4段（φ²刻み）、四角格子は5段（2倍刻み）
- 1段あたり五角形6,030個で一定。4段で24,120回、全画素は2,073,600回
- 1段上げるのに要るビット数は log2(φ⁴) = 2.7769。12〜14bit なら段5まで上げられ 8000×6000 が1枚に入る
- 画像のほうを回す普通の実装なら一手 8.3×10⁶ 回の乗算。番地を回すなら 18,120 回の加減で、**乗算器も三角関数表も要らない**

**限定**：四角格子も「90°刻みの向き＋2倍刻みの段」に限れば整数で閉じる。差が立つのは細かく向きを変える場合。

## 2. 形を読む道具として

**確定（2026-08-10）。**読みも整数で閉じた。

- **番地どうしの積 μ_m = Σ(c−c̄)^m** を型紙（理想の正n角形の横顔）に合わせる読み ── 1920×1080 に撒いた3/4/5/6角形64個を **62/62 全問正解**、三角形の適合率・再現率とも 1.0000
- w = N·c − Σc と置けば μ_m は **Z[ζ₁₀] の整数のまま**、|μ_m|² は p+qφ の整数対で出る（浮動小数との相対差 1e−15）
- 外積の符号は Im の符号＝`phi_sign` で決まるので、向き・左右・面積・折れも同じ帳簿に乗る
- 網膜が元から持つ10方向だけで読むと、m=6 が m=4 に折り返す（6角形が4角形に化ける）。積の読みに替えると折り返しは消える

**ただし精度の優位はない。**同じセル数の四角格子は三角形探しで 16/16・余分0（五角形は 16/16・余分1）。乱数点も 15/16。効いているのはセル数であって並べ方ではない。

**副産物（警告）**：標本器は**自分と同じ回転対称の図形をひいきする**。四角格子は4角形を、五角形の網膜は5角形を、相手より2倍以上小さいところから読む。形の弁別で並べ方を比べるときは、標本器の対称と図形の対称が一致していないかを先に確認しないと、並べ方の優劣を測ったつもりで対称の一致を測ることになる。

## 3. 標本器（イメージセンサー）として

**確定（窓に依らない）。**

- 四角格子は 5px の縞を 17.35px、6px の縞を 11.23px と誤読する。五角形の誤差は 0.0001 と 0.0010
- 理由は結晶学的制限：周期格子が持てる回転対称は n = 1,2,3,4,6 だけ。n=5 は 2cos72° = φ−1 で整数でない。**平面を埋め尽くせないことが、そのまま折り返さないことの理由**
- 同じ密度での比較：五角形は最小間隔 1.618／穴 2.591／折り返しの強さ 0.4077。**どちらでも一位ではないが、どちらでも最下位でないのは五角形だけ**（格子は折り返しで最悪、乱数は穴で最悪）
- **併用**（四角に五角を重ねる）は、再現で4割増しを払うだけで折り返しが消え、k の誤差は五角単独より小さい（0.0002）

**未決**：0.4077 が標本の大きさに依るかは未測定（1356点・領域72.1 での値）。

## 4. 番地と符牒として

**確定。**

- 13 は惰性素数で、13v は窓の外。**13 は番地の側にしかいない**
- F_13⁴ = 28,561 の番地に衝突0
- 五芒星416個は**全部が厳密な格子点**。移しの合成は1000手でも整数
- 移しの値段：**実長 × 残渣長 = √(絶対ノルム)**。単数は二本だけ（φ⁴族と φ⁶族）
- 用途判定は既に出ている ── **暗号にはならず符牒になる**（局所同型なので鍵にならない）

## 5. 収納場所（メモリー）として

**構造の側だけが言える。中身は一つも測っていない。**

言えること：

- 索引は整数で衝突なく引ける（F_13⁴ = 28,561）
- 目線の群（格子ベクトルの平行移動・ζ回転・φ²膨張）は番地に**整数の線形写像**として効く。36°回転と φ² 拡大に対する重み共有が**厳密**になる（四角格子で厳密なのは平行移動と90°回転だけ）
- 1段あたりのセル数が6,030で一定 ── 層の幅が一定
- 誤りが波及しない（ひし形が残渣の受け皿。誤りは局在する）
- 到達は段で対数的（1段ごとに視野 ×2.618）

言えないこと：

- **局所同型のため「見え」では場所を指せない**（半径25・五角形513枚を見ても一意0件）。内容参照では引けない。索引は番地でしか引けない
- 容量・書き込み・想起の検定は**一つもしていない**
- 学習器を載せた検定も一度もしていない。合成模様6クラス＋線形分類器（RD1）では**乱数点にも勝てていない**

### 「遠方の五芒星を繋いでしまう」の検定（TF13）

内側の五芒星から見た同心の殻に、相手も五芒星である個数：

| 殻の半径 | 1つの五芒星あたり |
|---|---|
| φ⁴ = 6.8541 | 3.03 個 |
| φ⁶ = 17.9443 | 1.32 個 |
| φ⁸ = 46.9787 | **0.26 個** |
| φ¹⁰ = 122.99 | **0 個** |

φ⁴と φ⁶ の二族（20本の生成元）で **416/416 すべてに到達できる**（最大12手・中央6手）。しかし届く距離は手数に**比例**する（一手あたり 12〜18px で頭打ち）。

**つまり平行移動だけでは遠方は繋がらない。**繋いでいるのは別の二つ。

1. **残渣の側** ── 実長 × 残渣 = √N なので、**実空間で大きく跳ぶほど残渣は小さい**（φ⁶ の跳びで残渣は ψ⁶ = 0.0557 しか動かない）。実空間で遠い二点が、残渣の帳簿では隣にいる。二つの距離は互いに逆数
2. **段** ── φ² 膨張で視野が一段ごとに 2.618倍。距離 D に届くのに要る手数は log D

## 6. 数の鎖（担体を要らない系・記事に載せてよい）

- 整数 n は円環 n 個の鎖。奇数は連続接続だけ（折れ108°のジグザグ）、偶数は2つ飛ばしの対を連続接続でつなぐ（折れ180°）。五角形の枚数は奇偶によらず 8n+2
- 部品は3種（1・独立した円環／2・2つ飛ばしの対／3・V字）。2と3が同じ鎖に同居する n は無い
- 平衡3進：3×(V字の個数) + 桁 = n。桁は 0/+1/−1 の三通りで、印は毎回ちょうど鎖の中心環に来る
- 隙間は4種だけ（細ひし形・五芒星・舟・正十角形）。舟は 3+2φ
- 円錐曲線：どちらの接続でも **楕円の離心率 × 双曲線の離心率 = √5/2**

**未解決**：面（910環）では V字は連連の3通りのうちの1つにすぎない。「1・2・3だけで作れる」は鎖に限った話で、面には持ち越せていない。
